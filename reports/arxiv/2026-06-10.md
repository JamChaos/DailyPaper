## 今日趋势

今天最明显的趋势，是 3D 表征继续从“能看”转向“能用”。3D Skew-Normal Splatting 和 GaussianZoom 都在改造 3DGS 的表达方式：前者把 primitive 从对称 Gaussian 推向可控 skewness，后者则把生成式 zoom-in 和多视图一致性、语义引导结合起来。它们共同说明，3DGS 仍在往更强的边界建模、更稳的跨尺度渲染演进。

另一条线是三维几何开始直接进入操作闭环。GraspFoM 把重建、3D foundation prior 和 grasp pose prediction 放到同一 latent 里，RePHO 则把 HOI 重建从运动上“看起来合理”推进到物理上“真的可行”。这类工作说明，3D 视觉不再只是输出 mesh 或 pose，而是在给机器人策略提供可消费的几何先验。

world model 和 Physical AI 方向也在重写接口。WLA-0 把 world modeling、语言推理和动作合成合并成一个统一接口，iMaC 则更激进地把图像本身当作动作 token，直接编码运动意图和接触约束。它们都在指向同一个方向: 更强的具身模型往往不是再堆一个动作头，而是重定义“世界状态”和“动作”的表示方式。

## 1. 3D Skew-Normal Splatting

- 作者: Xiangru Wu, Ke Fan, Yanwei Fu
- arXiv: https://arxiv.org/abs/2605.15010
- 发布时间与分类: 2026-05-14; 分类（按主题归类）: cs.CV
- 中文摘要: 这篇工作从 3DGS 的 primitive 形状入手，认为对称 Gaussian 在有限 primitive 预算下会损失边界和单侧结构的表达能力。作者把基础核改成 Azzalini Skew-Normal 之后，用可学习的 skewness 在对称 Gaussian 和更偏置的分布之间连续插值。这样既保留了解析可积性，也能更好地拟合尖边、薄结构和非对称表面。它属于那种看起来是“小改核函数”，但实质上在重新定义 3DGS 表达能力的工作。
- 方法亮点:
  - 用 Skew-Normal primitive 替代对称 Gaussian primitive。
  - 通过 bounded skewness 实现连续形状控制。
  - 采用解耦参数化和 block-wise optimization 提升训练稳定性。

## 2. GaussianZoom: Progressive Zoom-in Generative 3D Gaussian Splatting with Geometric and Semantic Guidance

- 作者: Jiale Shi, Jiarui Hu, Zesong Yang, Kaixuan Luan, Hujun Bao, Zhaopeng Cui
- arXiv: https://arxiv.org/abs/2605.18252
- 发布时间与分类: 2026-05-18; 分类（按主题归类）: cs.CV
- 中文摘要: GaussianZoom 把“极限放大”当成 3D 重建问题来做，而不是单纯的超分或后处理。作者用多视图一致的 super-resolution 模块配合 depth-based feature warping 和 VLM-driven detail synthesis，让局部细节在多视图间仍保持一致。再加上可扩展的 continuous LoD 层级，模型能够在更大放大倍率下保持平滑、无锯齿的跨尺度渲染。它对 3D 生成和场景重建都很有启发，因为它把几何和语义一起纳入了 zoom-in 过程。
- 方法亮点:
  - 结合几何一致性和语义引导做 progressive zoom-in 重建。
  - 用连续 LoD hierarchy 控制 Gaussian 可见性和跨尺度过渡。
  - 强调极端放大时的多视图一致性，而不是只追单帧观感。

## 3. GraspFoM: Towards Reconstruction-Driven Robotic Grasping with 3D Foundation Priors

- 作者: Dongli Wu, Xiaobao Wei, Hao Wang, Qiaochu Dong, Ying Li, Qingpo Wuwu, Ming Lu, Wufan Zhao
- arXiv: https://arxiv.org/abs/2606.08440
- 发布时间与分类: 2026-06-07; 分类（按主题归类）: cs.RO, cs.CV
- 中文摘要: GraspFoM 试图把三维重建变成抓取先验，而不是抓取前的中间步骤。它基于 SAM3D 构建共享 3D object latent，再用 anchor-initialized truncated pose-reasoning diffuser 直接生成连续、多峰抓取姿态。更关键的是，重建和抓取会通过 reconstruction-aware scorer 与 residual latent updater 互相修正，让几何表征朝着更适合操作的方向收敛。对于做机器人操作的人，这篇最重要的点是: mesh 和 3DGS 已经可以作为 grasp planning 的输入资产。
- 方法亮点:
  - 共享 3D object latent 同时服务 reconstruction 与 grasping。
  - 用 pose-reasoning diffuser 生成连续、多模态 grasp poses。
  - 输出 mesh 和 3DGS 两种三维资产形态。

## 4. Recovering Physically Plausible Human-Object Interactions from Monocular Videos

- 作者: Dingbang Huang, Etienne Vouga, Qixing Huang, Georgios Pavlakos
- arXiv: https://arxiv.org/abs/2606.05359
- 发布时间与分类: 2026-06-03; 分类（按主题归类）: cs.CV, cs.RO
- 中文摘要: RePHO 处理的是 HOI 重建里最典型的矛盾: 运动轨迹看起来对，不代表物理上真的对。作者先做 kinematic estimate，再把结果交给物理模拟器驱动的 RL policy 继续优化，目标是让重建出的交互更少穿插、更少悬浮。为了避免噪声轨迹把 RL 带偏，论文还设计了自更新式采样机制，挑出最有信息量、也最可靠的帧来训练。它的价值在于把 HOI 从“像”推进到“可物理成立”。
- 方法亮点:
  - 先 kinematic reconstruction，再用物理模拟和 RL 做 refinement。
  - 采用 adaptive sampling + dual self-updating 机制稳定训练。
  - 明确优化 physically plausible HOI，而不只是视觉相似度。
- 代码/数据集/项目页: 项目页: https://dingbang777.github.io/RePHO/；未找到代码仓库链接。
- 推荐阅读优先级: 高

## 5. Artiverse: A Diverse and Physically Grounded Dataset for Articulated Objects

- 作者: Denys Iliash, Jiayi Liu, Egor Fokin, Qirui Wu, Ali Mahdavi-Amiri, Manolis Savva, Angel X. Chang
- arXiv: https://arxiv.org/abs/2605.24403
- 发布时间与分类: 2026-05-23; 分类（按主题归类）: cs.CV, cs.RO
- 中文摘要: Artiverse 提供了一个面向 articulated objects 的大规模数据资源，目标不是只给表面几何，而是给能支撑功能建模和仿真的三维资产。数据集包含 5.4K 人工标注对象，覆盖 88 个类别，并标注功能部件、内部结构、运动学关系、多自由度关节，以及尺度、材质和质量等物理属性。作者还设计了半自动标注流程，把几何推理和人工验证结合起来，降低了标注成本。它的意义在于把 articulated objects 从“形状集合”推进成“可用于交互和仿真的物理对象库”。
- 方法亮点:
  - 同时提供功能部件、关节和物理属性标注。
  - 覆盖 88 类、5.4K 物体，适合功能理解与仿真。
  - 支持 part mobility analysis、articulated generation 和 physics-based interaction。

## 6. World-Language-Action Model for Unified World Modeling, Language Reasoning, and Action Synthesis

- 作者: Yi Yang, Zhihong Liu, Siqi Kou, Yiyang Chen, Yanzhe Hu, Jianbo Zhou, Boyuan Zhao, Zhijie Wei, Xiao Xia, Xueqi Li, Pengfei Liu, Zhijie Deng
- arXiv: https://arxiv.org/abs/2606.05979
- 发布时间与分类: 2026-06-04; 分类（按主题归类）: cs.RO, cs.AI, cs.LG
- 中文摘要: WLA-0 把 world modeling、语言推理和动作合成合并成一个统一的 embodied foundation model。它同时输入文本指令、图像和机器人状态，预测文本子任务、子目标图像和机器人动作，并通过 autoregressive Transformer 把 next state 拆成语义意图和细粒度物理动态两部分。更值得注意的是，world prediction 可以在推理时关闭，也可以在需要时打开做 test-time scaling，这让它比传统 WAM/VLA 接口更灵活。它对长时任务和跨 embodiment 学习都很有参考价值。
- 方法亮点:
  - 统一 world modeling、language reasoning 和 action synthesis。
  - 通过 World Expert 和 Action Expert 分离语义与物理动态监督。
  - 支持 test-time world prediction scaling。

## 7. iMaC: Translating Actions into Motion and Contact Images for Embodied World Models

- 作者: Zhenyu Wu, Xiuwei Xu, Yukun Zhou, Yifan Li, Qiuping Deng, Xiaofeng Wang, Zheng Zhu, Bingyao Yu, Ziwei Wang, Jiwen Lu, Haibin Yan
- arXiv: https://arxiv.org/abs/2606.09813
- 发布时间与分类: 2026-06-08; 分类（按主题归类）: cs.RO, cs.CV
- 中文摘要: iMaC 直接重写了 embodied world model 里的动作接口，认为关节角和末端位姿太窄，不足以表达复杂物理交互。它把原始视觉图像当作动作 token，让动作同时携带空间运动意图、接触约束和交互几何。模型由 image-action encoder 和 dynamic world predictor 两部分组成，前者把目标图像压成 action embedding，后者在这些 image actions 条件下学习环境转移。这个设计很像是在告诉具身模型: 动作不一定要是低维控制量，也可以是带几何语义的视觉条件。
- 方法亮点:
  - 用图像替代结构化控制向量作为 action representation。
  - 同时编码 motion intent、contact constraints 和 physical dynamics。
  - 兼顾 future state prediction 和 closed-loop control。

## 值得深读

1. WLA-0
   这篇最值得世界模型和长时任务方向优先读。它把 world prediction 和 language reasoning 绑在同一个接口里，而且还允许推理时按需开启世界分支，思路比传统 WAM/VLA 更完整。
2. iMaC
   如果你关心 Physical AI 或 embodied world models，这篇非常重要。它把动作接口从低维控制量改成图像 token，可能会影响后续对接触、几何和跨 embodiment 泛化的建模方式。
3. GraspFoM
   这是“3D 重建如何服务机器人”的直接例子。它把 3D foundation prior、mesh、3DGS 和 grasp planning 合在一起，说明几何表征已经开始直接喂给操作策略。
4. RePHO
   HOI 方向最值得看的点在这里: 不是重建出能看的交互，而是重建出物理上成立的交互。对第一人称操作、灵巧手学习和交互数据生成都很有启发。
5. GaussianZoom
   这篇适合关注 3D 生成和 3DGS 的人。它把几何一致性、语义引导和极限 zoom-in 放到一起，说明 3DGS 还在往更高分辨率和更强跨尺度一致性演进。
