## 今日趋势

今天的核心信号是 sim-ready 世界正在取代“只可观看”的三维生成：CARLA-GS、EmbodiedGen V2、RoboSnap、SPEAR 和 WildCity 都把重建/生成结果接到物理执行、闭环评测或策略训练里。

3DGS 的使用继续从新视角合成外扩到机器人地图和仿真基础设施：GeoGS-SLAM 做 geometry-only Gaussian SLAM，NoDrift3R 处理长序列 pose drift，RoboSnap 和 CARLA-GS 则把 Gaussian 场景变成可交互 sim layer。

VLA/机器人操作的重点明显转向“状态、记忆、触觉与注意力”的结构化接入：GeoProp 显式对齐本体状态和视觉 token，LaMem-VLA/NativeMEM 处理长程记忆，Pelican-VLA 诱导接触区域注意，TouchWorld 把触觉 world model 接进灵巧操作闭环。

world model 的评测与可信度开始变得更严肃：Admissibility for World-Model Simulators 指出视觉质量不能替代动作响应验证，Instruction Leakage 论文提醒语言目标可能污染 spatial grounding，Geometric Collapse 则说明 dense geometry model 仍缺少物理因果自检。

场景级理解正在向长期、跨视场、多主体和人类协作扩展：PUF 关注 uncertainty-aware 3D scene graph 融合，SpaR3D-MoE 做稀疏视图 3D 推理，G-PROBE/CILC 处理多机器人定位与安全，CoMind 为 human-object interaction 和协作辅助提供带 3D scans 的数据资源。

最值得优先深读的是 CARLA-GS: Decoupling Representation, Reasoning, and Physics Simulation for Autonomous Driving Corner-Case Synthesis、EmbodiedGen V2: An Agentic, Simulation-Ready 3D World Engine for Embodied AI、GeoGS-SLAM: Geometry-Only Gaussian Splatting for Dense Monocular SLAM、NoDrift3R: Raymap-Guided Coupling for Drift-Robust Unposed Feed-Forward 3D Reconstruction、WildCity: A Real-World City-Scale Testbed for Rendering, Simulation, and Spatial Intelligence、RoboSnap: One-Shot Real-to-Sim Scene Generation for Generalizable Robot Learning and Evaluation、SPEAR: A Simulator for Photorealistic Embodied AI Research、PUF: Plug-and-Play Uncertainty-Aware Fusion for Online 3D Scene Graph Generation、GeoProp: Grounding Robot State in Vision for Generalist Manipulation、TouchWorld: A Predictive and Reactive Tactile Foundation Model for Dexterous Manipulation。它们共同指向一个判断：三维视觉与 Physical AI 的研究重心正在从“可重建/可生成”转向“可执行、可验证、可记忆、可闭环使用”的世界表示。

## 3. GeoGS-SLAM: Geometry-Only Gaussian Splatting for Dense Monocular SLAM

- 中文摘要: GeoGS-SLAM 直接质疑 3DGS-SLAM 是否必须同时优化外观和几何，答案是对机器人任务而言几何可能更关键。它提出 Geometry-only Gaussian Splatting，只保留空间参数，从而减少超过 80% 的 per-primitive 参数，并强化光照变化下的鲁棒性。系统还用局部平面初始化和 loop closure 后的全局 Gaussian map 更新避免地图撕裂。对 dense monocular SLAM 来说，这篇提供了一个很清晰的方向：3DGS 可以被压成几何优先的在线地图表示。
- 方法亮点:
  - geometry-only Gaussian primitives with far fewer parameters
  - single-view/multi-view geometric supervision and local-plane initialization
  - loop-closure map update that globally transforms the Gaussian map

## 11. Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation

  - retrieval and condensation of historical evidence into compact memory tokens
  - memory tokens woven into the same embedding sequence as current observation and instruction
- 代码/数据集/项目页: 项目页 https://github.com/quhongyu/LaMem-VLA；代码 https://github.com/quhongyu/LaMem-VLA
