## 今日趋势

- World model 与机器人策略正在从“预测更多像素”转向“把几何、动作和物理结构写进 latent”：GWM-VLA 聚合多视图几何，4D-WAM 对齐 3D 轨迹场，JEPA-WAM 共享状态转移与动作预测，World Tokens 则把视频 world model 限定为训练期监督。
- 物理可信度开始成为独立研究对象：PhyS 用真实交互视频蒸馏物理先验，LDR 把运动学积分显式嵌入 latent，WorldSimProbe 则以可观测模拟器契约检验动作是否真正引起对应运动和环境响应。
- 3DGS 的前沿问题从静态、已标定场景转向弱标定、异步传感和退化观测：FlexSplat 联合估计相机与深度，EvTrajGS 优化连续时间事件轨迹，EndoMD-SLAM 用记忆门控与静态/瞬态分解保护持久地图。
- Physical AI 的表示与基础设施同步靠近可执行世界：PhysX-CoT 生成可碰撞、可关节化的 3D 资产，NewtonGS 用显式牛顿状态驱动 Gaussian 对象，reverse-sweep adjoint 则把百万级接触软体的可微仿真推向单卡规模。

## 最值得深入阅读

1. **PhysX-CoT**：把单图到 simulation-ready 3D 从端到端 token 输出改写为可监督、可验证的部件级物理推理链，对机器人资产生成最直接。
2. **GWM-VLA**：展示多视图几何聚合如何进入 latent world model 与 flow-matching 动作头，是 3D foundation model 接入 VLA 的清晰范式。
3. **WorldSimProbe**：将“视觉上像未来”与“动作条件模拟器真的忠实”区分开，适合用作 world model 研究的评测底座。
4. **Distilling Physical Priors into Streaming World Models**：真实物理交互数据、教师蒸馏和时间信用分配形成完整训练链，直接面向长时物理一致性。
5. **FlexSplat**：以联合几何前端消除 query-based 3DGS 对已知相机的依赖，对无标定多视图重建很有实用价值。
6. **Differentiate the Solver, Not the Equation**：从执行过的局部求解器构造离散伴随，兼顾梯度精确性、内存和百万级接触规模，可能显著降低 Physical AI 的优化成本。

**中文摘要**: PhysX-CoT 面向从单张图像生成可直接进入机器人仿真的 3D 资产，指出全局坐标 token 流会纠缠部件布局、局部形状和物理属性。方法将生成过程展开为机器可解析的部件级状态序列，显式监督分解、2D/3D grounding、关系、粗几何与表面线索。3D box 负责部件放置，局部 code 负责形状，CoT-aligned GRPO 再联合优化解析有效性、几何、尺度和物理一致性。在统一重训协议下，方法超过最接近的完整任务基线，生成资产在 Unreal Engine 5 中具有较高的解析、碰撞和关节有效率。

**方法亮点**: structured physical CoT；part-level 2D/3D grounding；box-placement / local-shape factorization；CoT-aligned GRPO；simulation-ready validation。

## 4. FlexSplat: Flexible Feed-Forward 3D Gaussian Splatting without Point Cloud Correspondence

**作者**: Amir Sabbaghziarani, Hanting Ye, Maria Gorlatova, Yi Ding

**arXiv / 发布时间与分类**: [arXiv:2608.07937](https://arxiv.org/abs/2608.07937) | 公告批次: 2026-08-11；v1 submitted: 2026-08-08 05:52:26 UTC | categories: cs.CV

**中文摘要**: FlexSplat 从未标定的 object-centric 多视图图像直接生成紧凑 3D Gaussians，移除了 query-based feed-forward 3DGS 对已知相机位姿的依赖。联合训练的 geometry transformer 预测每张图的相机与深度，并用深度引导 Gaussian 参数化和多视图 deformable cross-attention。带不确定性权重的深度一致性目标允许几何前端适应重建误差，而跨视图共识吸收残余位姿和深度偏差。方法在 ShapeNet-SRN 与 GSO 上无需真值位姿或深度即可接近 posed 方法，Gaussian 数量也不随像素网格和视图数增长。

**方法亮点**: calibration-free feed-forward 3DGS；joint camera/depth prediction；depth-guided Gaussian queries；uncertainty-weighted depth consistency。

**资源**: 项目页未见；[代码](https://github.com/amir-sbg/FlexSplat)；数据集未单独发布。

**推荐阅读优先级**: 高

## 6. NewtonGS: Physics-Structured Object-Level Neural Newtonian Dynamics for Gaussian Scene Animation

**作者**: Lianlei Shan, Feiyang Ye, Yan Chen, Yong Wu

**arXiv / 发布时间与分类**: [arXiv:2608.07598](https://arxiv.org/abs/2608.07598) | 公告批次: 2026-08-11；v1 submitted: 2026-08-06 09:41:43 UTC | categories: cs.CV

**中文摘要**: NewtonGS 为静态 Gaussian 场景中的对象定义可控、可 rollout 的显式动力学状态，而非只拟合逐时刻形变。每个对象由 22 维状态描述位姿、线/角速度、各向异性尺度及变化率、质量和接触属性。Gaussian-NND 将解析平移、四元数运动学、重力、阻尼和尺度恢复与学习式连续/接触残差组合，再用离散事件映射处理地面碰撞。State-32 与 Gaussian-32 的合成实验说明该状态既能提高轨迹预测，也能直接变换对象所属 Gaussians，但真实复杂接触的泛化仍待验证。

**方法亮点**: 22D object state；analytic-plus-residual Newtonian dynamics；discrete contact event map；state-to-Gaussian affine animation。

**资源**: 项目页、代码和数据集下载链接未见；论文介绍 State-32 与 Gaussian-32。

**推荐阅读优先级**: 中

## 12. Differentiate the Solver, Not the Equation: Reverse-Sweep Adjoints for Block Implicit Simulation

**中文摘要**: 论文提出 solver-level differentiation，直接对实际执行的 block implicit updates 求导，而非对收敛方程组装全局 Jacobian。离散伴随按反序执行局部 adjoint update，使 backward 镜像 forward 的有序局部求解，并避免构造全局系统。在 Vertex Block Descent 上，reverse colored Gauss-Seidel 只需求解局部 3×3 伴随问题，且与同一有限迭代 forward 的自动微分达到机器精度一致。相同代码与 GPU 对比中，它比展开自动微分快 33 倍、内存少 71 倍，并把可微弹性动力学扩展到单卡 100 万个接触耦合软体。

**方法亮点**: solver-level differentiation；reverse-sweep discrete adjoint；local 3×3 solves；million-body differentiable elastodynamics。

**资源**: 项目页、代码和数据集链接未见。

**推荐阅读优先级**: 高

## 14. EvTrajGS: Accurate and Efficient 3D Gaussian Splatting from Unposed Event Streams

**作者**: Zixuan Chen, Jiakai Zhang, Junhao Dong, Guangcong Wang, Jianhuang Lai, Yew-Soon Ong, Xiaohua Xie

**arXiv / 发布时间与分类**: [arXiv:2608.08585](https://arxiv.org/abs/2608.08585) | 公告批次: 2026-08-11；v1 submitted: 2026-08-09 09:00:30 UTC | categories: cs.CV

**中文摘要**: EvTrajGS 从无位姿事件流联合优化相机运动和 3D Gaussian 场景，目标是在廉价粗位姿初始化与昂贵增量 SLAM 之间取得平衡。连续时间轨迹由离散相机位姿初始化，为 pose refinement 提供统一表示。相邻轨迹状态被聚合为时间耦合位姿，loss-reweighted event sampling 则把训练资源集中到重建不足的时间段。合成和真实数据上，方法同时提升几何重建与位姿精度，报告 PSNR 提高 3.8 dB、ATE RMSE 降低 40% 以上。

**方法亮点**: unposed event-stream 3DGS；continuous-time camera trajectory；temporally coupled pose；loss-reweighted event sampling。

## 15. EndoMD-SLAM: Endoscopic Gaussian Splatting SLAM under Optical Degradation with Memory and Static-Transient Decomposition

**作者**: Nuo Chen, Kangqi Ni, Lulin Liu, Joga Ivatury, Ying Ding, Farshid Alambeigi, Tianlong Chen, Zhiwen Fan

**arXiv / 发布时间与分类**: [arXiv:2608.08949](https://arxiv.org/abs/2608.08949) | 公告批次: 2026-08-11；v1 submitted: 2026-08-09 22:59:01 UTC | categories: cs.CV

**中文摘要**: EndoMD-SLAM 处理内窥镜中碎屑、水冲洗等相机附着退化破坏多视图光度一致性的问题，避免污染被永久融合进 3D 解剖地图。tracking 端的 memory-driven gating 会检测不可靠观察、暂停地图更新，并利用历史 keyframe 做 drift-aware relocalization。mapping 端以自监督 static-transient decomposition 把视觉污染放入独立瞬态场，保护持久 Gaussian 几何。作者构建退化专用结肠镜基准，实验将 absolute trajectory error 降低 91%，PSNR 提高 9.9 dB。

**方法亮点**: memory-driven observation gating；historical-keyframe relocalization；static-transient Gaussian decomposition；degradation-focused benchmark。

**资源**: [项目页](https://endomd-slam.github.io/)；[代码](https://github.com/phai-lab/EndoMD-SLAM)；数据集未见独立下载直链。

**推荐阅读优先级**: 高
