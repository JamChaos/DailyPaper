## 今日趋势

2026-06-29 官方公告批次里，世界模型明显从“能生成视频”转向“能作为物理可用的模拟器”: PhysisForcing、P3Sim、DiM-WAM、CascadeOcc、Directing the World 和 MemoBench 都在处理动作条件、空间记忆、长期 rollout、物理一致性和诊断评测。

三维重建和生成继续走向结构化、可部署: HAT-4D 从单目视频恢复多物体 4D 交互，ReScene 面向仿真就绪室内场景，StructSplat 与 Structured-Li-GS 分别攻克无标定稀疏视图和 LiDAR 约束 3DGS，CoIn 把 2D inpainting 与 3DGS 双向闭环。

机器人方向的重点是“显式结构注入策略”: SimFoundry 用真实视频构建可编辑 digital twins，Direct Action-Head Injection 把 grounded 3D point 直接喂给动作头，SceneBot/CWI 用接触标签和组合模仿统一 humanoid loco-manipulation，DexCompose、PA-BiCoop、in-grasp manipulation 和 S2-VLA 都在解决长时程、多手/多指协作中的角色、接触和阶段切换。

具身空间评测也在变细: AirGroundBench 评估 UAV-UGV 多视角协作，LocalNav 关注端侧 VLM 物体导航，LXD-SLAM 把多传感器 dense mapping 做成可插拔组合。今天的主线不是单点指标刷新，而是把几何、物理、动作、记忆和评测闭合成系统。

最值得优先深读的是 PhysisForcing、P3Sim、HAT-4D、SimFoundry、ReScene、StructSplat、DiM-WAM、DexCompose、CascadeOcc 和 Direct Action-Head Injection。它们对三维重建、三维生成、世界模型、机器人和 Physical AI 的共同启发是: 下一步的核心不只是更逼真的渲染，而是让表示能承载可控动作、可验证物理、可复用仿真资产和稳定的闭环策略。

## 4. LXD-SLAM: LiDAR+X Dense SLAM with Configurable Sensor Combinations

- 中文摘要: LXD-SLAM 以 3D LiDAR 为中心，将 camera、IMU、wheel encoder 和 GNSS 做成最多 32 种可插拔组合，目标是在复杂环境下保持全局一致 pose 与 dense mapping。方法使用统一的 Iterative Error-State Kalman Filter，将点到 mesh 距离和视觉重投影误差放进同一个更新框架。环境由连续多层 Gaussian Process sub-mesh 表示，并支持 visual feature 的 ray-to-mesh depth recovery。它对机器人部署的意义在于减少“每个传感器组合一套 SLAM”的工程碎片化。

  - unified IEKF update combines point-to-mesh and visual reprojection terms

## 9. CoIn: Comprehensive 2D-3D Inpainting with Gaussian Splatting Guidance

- 作者: Hana Kim, Minje Kim, Tae-Kyun Kim
- arXiv: https://arxiv.org/abs/2606.27584
- 发布时间与分类: arXiv API published 2026-06-25T22:24:27Z; official announcement batch: 2026-06-29 (/list cs.CV/new, cs.AI/new); categories: cs.CV, cs.AI
- 中文摘要: CoIn 处理 3D scene inpainting 中多视角 mask 严格、任务局限于 object removal、跨视角不一致等问题。它先用 2D diffusion inpainting 生成初始视图，再通过 Reference Adaptive GS with Feature Attention 做粗 3DGS 重建。随后 3DGS 反过来通过 reference feature warping 指导 diffusion，让 3D->2D 和 2D->3D 信息双向循环。最后的 Texture-Enhancing Discriminator 提升 photometric realism，因此能同时支持物体移除、插入和任意形状 mask。
- 方法亮点:
  - bridges 2D diffusion inpainting and 3DGS through bidirectional consistency
  - reference adaptive GS builds coarse 3D scenes from inpainted views
  - GS-based feature warping improves multi-view consistency

## 深读建议

- 优先读世界模型与物理模拟链条: PhysisForcing、P3Sim、DiM-WAM、CascadeOcc、Directing the World、MemoBench 方向相邻，其中 PhysisForcing 和 P3Sim 最接近机器人可用的物理世界模型。
- 优先读三维资产/场景生产链条: HAT-4D、SimFoundry、ReScene、StructSplat、CoIn 共同说明，未来的 3D 生成系统需要同时产出几何、关系、物理可执行性和可编辑资产。
- 优先读机器人策略结构化注入: Direct Action-Head Injection、DexCompose、SceneBot、S$^2$-VLA 展示了一个趋势，即把 3D 点、接触标签、手指角色或任务阶段显式喂给策略，比单纯扩大 VLA backbone 更直接。
- 对三维重建研究的启发: 稀疏/无标定、多传感器和交互场景越来越重要，重建结果若不能进入仿真、导航或 manipulation，就很难成为 Physical AI 的核心资产。
- 对三维生成和世界模型研究的启发: 视觉逼真已经不够，下一阶段要把动作条件、相机几何、场景记忆和物理约束纳入训练和评测，否则难以支撑长期闭环决策。
