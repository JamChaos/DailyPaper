## 今日趋势

今天最强的三维视觉主线是 3DGS/几何表示继续向可编辑、可评估、可部署前馈系统推进：ATSplat 做自适应前馈 3DGS，LB-Edit 处理多视图编辑一致性，MR-Compare 把 3DGS 与 mesh 放到 mixed reality 中做现场对齐评估，GaussianSeed 则把 Gaussian hierarchy 用于高分辨率 3D occupancy。

world/action model 明显更重视几何落地和可执行性：KineBench 用 6D end-effector pose 和 simulator 闭环验证 embodied world models，PerceptDrive 强调 perception priors 到 planning 的路由，SafeGen 用 depth-aware projection 生成安全关键驾驶视频，Koopman Dreamer 用谱约束稳定长 horizon latent imagination。

机器人操作方向集中在从人类数据和语言条件中获得可执行几何动作：HOST 从单个 human video 快速获取技能，SeededGrasp 让 VLM 预测 seed point 再交给抓取生成器，EgoRecovery 用 egocentric recovery data 学失败恢复，LENS 则把 clutter scene 简化成任务相关抽象。

导航和 humanoid 方向从 benchmark 走向真实部署：NavVerse 补齐 indoor-to-outdoor 连续导航，Milo 给出低成本导盲犬平台，DEED 和 miniature humanoid tele-loco-manipulation 都强调 VLA/VR/RL 在真实人形机器人中的系统集成。

最值得深入阅读的是 ATSplat、Crowd4D、KineBench、PerceptDrive、SeededGrasp、HOST、LENS、StreamHOI、GaussianSeed 和 StereoFlow。它们共同显示出一个趋势：三维表示正在从视觉重建结果变成生成、评测、规划和机器人闭环控制共享的中间状态。

- 中文摘要: ATSplat 是 compact feed-forward 3D Gaussian Splatting 框架，目标是把 optimization-based 3DGS 的自适应 primitive allocation 带回前馈方法。它先把 patch-level depth 与 camera cues 提升成稀疏 3D anchor tokens，再让每个 token 回归带可学习 3D offsets 的局部 Gaussians，从而摆脱像素网格对 primitive 数量和位置的限制。Adaptive Token Expansion 用 rendering error map 监督 token uncertainty，只在困难区域扩展。论文报告在 RealEstate10K 和 DL3DV 上达到 SOTA 质量，同时 Gaussian 数量减少 5.7 倍以上，单 GPU 低于一秒完成重建。
- 方法亮点:
  - Adaptive 3D Tokens as sparse scaffold for feed-forward 3DGS
  - local Gaussian regression with learnable 3D offsets
  - uncertainty-guided Adaptive Token Expansion supervised by rendering errors
