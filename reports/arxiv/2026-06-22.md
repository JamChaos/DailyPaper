## 今日趋势

最新批次最明显的主线是机器人数据与策略正在快速“几何化”。Pose6DAug、One Demo is Worth a Thousand Trajectories、EquiVLA、Co-VLA 和 EventVLA 都不是只扩大数据量，而是在多视角一致性、相机/物体 6D pose、旋转等变性、双臂协调结构和稀疏关键视觉记忆上加约束。这说明 VLA/visuomotor policy 的下一步瓶颈不是单纯更大的 backbone，而是如何把 3D 几何、物理可行性和长程上下文变成可训练的策略先验。

第二条线是 world action model 正在从“生成未来视频”转向“更便宜、更任务相关的状态变化建模”。ImageWAM 直接质疑机器人 WAM 是否需要完整视频生成，MemoryWAM 则强调持久记忆与非马尔可夫操作任务；Holo-World 把相机、物体和天气控制统一到视频 world model 中。对机器人和 Physical AI 来说，这些工作共同指向一个启发: world model 的价值不在于预测所有像素，而在于保留会影响动作选择的可控变化、长期证据和几何结构。

第三条线是三维重建与空间智能基础设施继续向真实部署靠近。VisDom、Geometry-Preserving 3DGS Calibration、MMD-SLAM 和 LIT-GS 都围绕稀疏视角、传感器标定、SLAM 和弱光/热成像条件下的几何稳定性；Occ-VLM、SpatialSV、3D-DLP 和 3D Scene Graphs 则把 3D occupancy、显式 2D-to-3D lifting、object-centric particles 和场景图作为 VLM/机器人可消费的空间表示。最值得优先深读的是 Pose6DAug、ImageWAM、MemoryWAM、VisDom、Occ-VLM、3D-DLP、Generating Robot Hands from Human Demonstrations 和 TaCauchy；它们分别对多视角机器人数据增强、WAM 设计、长程机器人记忆、稀疏重建约束、具身场景理解、object-centric 3D 表征、手部 embodiment 设计和触觉物理仿真有直接启发。

## 1. Pose6DAug: Physically Plausible Multi-view Object Swapping for Robot Data Augmentation

- 作者: Jonghoon Lee, Seong Hyeon Park, Byungwoo Jeon, Minha Lee, Jinwoo Shin
- arXiv: https://arxiv.org/abs/2606.20118
- 发布时间与分类: arXiv v1 submitted 2026-06-18T11:41:25Z；官方公告批次 2026-06-19 (Friday, 19 June 2026)；分类: cs.RO, cs.LG
- 中文摘要: Pose6DAug 关注 VLA policy 在 novel/OOD objects 上失败后，如何不用重新采集遥操作数据就补足失败模式。它利用成功 episode 中已经存在的物理可行轨迹和标定多视角观测，只替换被操作物体，并用显式 mesh 与时间一致的 6D pose trajectory 保证跨视角几何一致。相比普通 2D video editing，这种 3D object swapping 更能处理遮挡和 egocentric 视角下的物理合理性。论文报告在新物体上微调 VLA 后成功率相对提升 16.5%，同时不损害 in-distribution 表现。
- 方法亮点:
  - 基于成功 episode 的 failure-driven data augmentation，避免为每个失败物体重新遥操作采集。
  - 在 3D 中锚定目标物体 mesh，并由时间连贯的 6D pose trajectory 驱动。
  - 保持多视角渲染一致性与物理可行轨迹，对 VLA novel-object generalization 直接有效。

## 2. One Demo is Worth a Thousand Trajectories: Action-View Augmentation for Visuomotor Policies

- 作者: Chuer Pan, Litian Liang, Dominik Bauer, Eric Cousineau, Benjamin Burchfiel, Siyuan Feng, Shuran Song
- arXiv: https://arxiv.org/abs/2606.19586
- 发布时间与分类: arXiv v1 submitted 2026-06-17T20:41:13Z；官方公告批次 2026-06-19 (Friday, 19 June 2026)；分类: cs.RO
- 中文摘要: 这篇论文试图从单条真实 eye-in-hand demonstration 生成大量视觉真实且动作可行的增强轨迹。方法先用适配 fisheye wide-FoV 相机的 Gaussian Splatting 重建并编辑 3D 场景，再通过轨迹优化生成平滑、无碰撞且适合 novel-view 渲染的动作轨迹。它主要解决初始构型变化、未见障碍物和 OOD 观察导致 visuomotor policy 崩溃的问题。对低数据机器人学习而言，这是把 3DGS 从渲染工具变成数据扩增引擎的典型例子。
- 方法亮点:
  - 从便携平行夹爪和单 fisheye 相机采集的一条示范生成多视角动作-视觉增强。
  - 使用 wide-FoV Gaussian Splatting 重建/编辑场景和未见障碍物。
  - 通过 trajectory optimization 保证动作轨迹平滑、无碰撞、可渲染。

## 3. EquiVLA: A General Framework for Rotationally Equivariant Vision-Language-Action Models

- 作者: Thien-Loc Ha, Quang-Tan Nguyen, Trong-Bao Ho, Long Dinh, Minh Duc Nguyen, Gia-Binh Nguyen, Pham Tri Quang, Minh N. Vu, Duy M. H. Nguyen, An Thai Le, Ngo Anh Vien

- 发布时间与分类: arXiv v1 submitted 2026-06-18T04:36:57Z；官方公告批次 2026-06-19 (Friday, 19 June 2026)；分类: cs.RO
- 中文摘要: EquiVLA 认为现有 VLA 缺少几何归纳偏置，导致在训练朝向之外泛化需要大量额外数据。它提出适用于冻结 VLM backbone 与 flow-matching DiT action head 的 SO(2)-equivariant VLA 框架。EquiPerceptor 从冻结 ViT features 产生近似旋转等变的视觉表示，EquiActor 则给出严格 SO(2)-equivariant 的动作头。论文在 LIBERO、CALVIN 和真实 Mobile ALOHA 任务上都报告明显提升，说明等变性仍是机器人 foundation policy 的高性价比结构先验。
- 方法亮点:
  - 建立从相机观察到 action sequence 的近似 SO(2) equivariance chain。
  - EquiPerceptor 适配冻结 ViT/VLM features，减少重新训练 backbone 的成本。
  - EquiActor 将 flow-matching Diffusion Transformer action head 改造成严格旋转等变。

## 4. Co-VLA: Coordination-Aware Structured Action Modeling for Dual-Arm Vision-Language-Action Systems

- 作者: Yandong Wang, Jiaqian Yu, Xiongfeng Peng, Lu Xu, Yamin Mao, Weiming Li, Jaewook Yoo, Dongwook Lee, Daehyun Ji, Mingbo Zhao, Chao Zhang
- arXiv: https://arxiv.org/abs/2606.20285
- 发布时间与分类: arXiv v1 submitted 2026-06-18T14:28:37Z；官方公告批次 2026-06-19 (Friday, 19 June 2026)；分类: cs.RO
- 中文摘要: Co-VLA 针对双臂 VLA 中“隐式学出协调”不足的问题，提出显式结构化动作建模。它用 Structured Action Expert 替代单体 action head，把共享 latent 用于任务级协调意图，把 residual latents 用于两只手臂的执行修正。部署时，Latent-Aware Controller 在关节命令层调节同步强度、不对称执行、平滑性和安全约束。结果显示在紧耦合双臂任务和 OOD 真实场景中都比 monolithic baseline 更稳定。

## 5. EventVLA: Event-Driven Visual Evidence Memory for Long-Horizon Vision-Language-Action Policies

- 作者: Ganlin Yang, Zhangzheng Tu, Yuqiang Yang, Sitong Mao, Junyi Dong, Tianxing Chen, Jiaqi Peng, Jing Xiong, Jiafei Cao, Jifeng Dai, Wengang Zhou, Yao Mu, Tai Wang

- 发布时间与分类: arXiv v1 submitted 2026-06-18T11:11:37Z；官方公告批次 2026-06-19 (Friday, 19 June 2026)；分类: cs.CV
- 中文摘要: EventVLA 解决长程机器人操作中任务相关视觉线索会被遮挡或消失的问题。它不是保存庞大的历史帧 buffer，而是维护 foundational visual anchors 和动态 Keyframe Evidence Memory。KEM 从 VLA latent embeddings 直接预测未来关键帧概率，提前保存具有因果价值的视觉事件。论文还提出 RoboTwin-MeM 诊断 benchmark，并在模拟和真实双臂任务上报告平均成功率相对 memory-augmented VLA 大幅提升。
- 方法亮点:
  - 稀疏 visual evidence memory 兼顾长程上下文和低延迟。
  - Keyframe Evidence Memory 根据未来因果价值选择保存当前观察。
  - RoboTwin-MeM 专门评估非马尔可夫、需要交互视觉证据的 manipulation tasks。

## 6. ImageWAM: Do World Action Models Really Need Video Generation, or Just Image Editing?

- 作者: Yuyang Zhang, Wenyao Zhang, Zekun Qi, He Zhang, Haitao Lin, Jingbo Zhang, Yao Mu, Xiaokang Yang, Wenjun Zeng, Xin Jin
- arXiv: https://arxiv.org/abs/2606.19531
- 发布时间与分类: arXiv v1 submitted 2026-06-17T19:25:28Z；官方公告批次 2026-06-19 (Friday, 19 June 2026)；分类: cs.CV, cs.RO
- 中文摘要: ImageWAM 直接挑战 video-based world action model 的默认设计: 机器人动作预测未必需要生成完整未来视频。它把 pretrained image editing model 的 denoising KV cache 当作紧凑 world-action context，供 flow-matching action expert 使用，而推理时不解码目标帧。这样模型更聚焦当前到目标状态的任务相关视觉变化，减少对无关外观和长程像素预测的计算浪费。论文报告在模拟和真实实验中优于 VLA 与 WAM baseline，同时 FLOPs 降到视频 WAM 的约 1/6、延迟约 1/4。
- 方法亮点:
  - 用 image editing prior 替代完整视频生成，聚焦 action-relevant visual change。
  - 推理时复用 denoising KV caches，不需要显式生成目标图像。
  - 对 WAM 设计提出清晰取舍: 预测任务相关状态变化优先于预测所有未来像素。
- 代码/数据集/项目页: 项目页 https://zhangwenyao1.github.io/ImageWAM/；代码 https://github.com/yuyangalin/ImageWAM；模型 https://huggingface.co/collections/yuyangalin/imagewam。

  - 在长程记忆依赖的模拟和真实 manipulation 任务上兼顾成功率与推理效率。

## 10. 3D-DLP: Self-Supervised 3D Object-Centric Scene Representation Learning

- 作者: Ellina Zhang, Madhaven Iyengar, Amir Zadeh, Chuan Li, Deepak Pathak, David Held, Tal Daniel
- arXiv: https://arxiv.org/abs/2606.19451
- 发布时间与分类: arXiv v1 submitted 2026-06-17T18:00:08Z；官方公告批次 2026-06-19 (Friday, 19 June 2026)；分类: cs.LG, cs.CV, cs.RO
- 中文摘要: 3D-DLP 是自监督 object-centric 3D scene representation，把 RGB-D 或 voxel observation 分解为一组 3D latent particles。每个粒子编码 3D keypoint、bounding box 尺寸和 appearance，并通过重建目标学习可解释 segmentation maps。论文展示了通过操控粒子位置生成新场景配置的可控性，并将紧凑 3D particles 用于下游机器人操作。相比 dense 3D input，这类 object-centric latent 更适合长期记忆、规划和低成本策略输入。
- 方法亮点:
  - 以 3D latent particles 表示物体级实体和几何属性。
  - 自监督重建目标学习可解释 per-particle segmentation。
  - 紧凑 object-centric 3D latent 可直接提升机器人 manipulation 下游表现。
- 代码/数据集/项目页: 项目页 https://eubooks3003.github.io/3d-dlp；代码 https://github.com/Eubooks3003/3d-dlp。

## 总结与建议阅读顺序

今天最值得优先读的论文是 Pose6DAug、ImageWAM、MemoryWAM、VisDom、Occ-VLM、3D-DLP、Generating Robot Hands from Human Demonstrations 和 TaCauchy。若关注机器人策略泛化，建议先看 Pose6DAug、EquiVLA、Co-VLA 和 EventVLA，它们共同说明 VLA 的增益来自结构化几何、协调约束和关键事件记忆，而不只是更大模型。若关注 world model 与 Physical AI，ImageWAM 和 MemoryWAM 提供了很好的反直觉设计: 少生成全视频，多保留与动作相关的变化和长期状态。

三维重建方向可以优先读 VisDom、Geometry-Preserving 3DGS Calibration、MMD-SLAM 和 LIT-GS。它们分别从 sparse-view visibility、metric geometry preservation、结构先验 SLAM 和 LiDAR-thermal 平面约束说明 3DGS 的核心问题正在从“好看”走向“可标定、可定位、可部署”。具身空间理解方向则建议把 Occ-VLM、SpatialSV、3D-DLP 和 3D Scene Graphs 放在一起看: 一个用 occupancy grounding 复用 VLM，一个让 MLLM 显式 lift 到深度/位姿/点云，一个学习 object-centric 3D particles，一个整理机器人可用的语义几何图结构。
