## 今日趋势

- 3D 表示从单纯重建和渲染走向可理解、可编辑、可复用：Scenix 用可执行 scene program 组织稀疏视图重建，InstanceSplat 把实例和语言语义写入共享 Gaussian，CANIS 则用生成模型提供语义朝向先验。
- World model 的核心监督从像素预测转向结构化状态、记忆和动作因果：SimWAM、UniJEPA、WorldTrace、PSG-JEPA、AtlasVLA 和 PILOT 分别处理训练时视频监督、统一 latent、长时记忆、物理状态、持久世界状态与意图—轨迹分解。
- 几何感知正在直接连接具身决策：WNM-3D 将 3D 场景 token 接入闭环导航，C2Dex 用接触几何把人类 HOI 迁移到灵巧手，LifelongCrossNav 用持久 3D 语义记忆支持跨楼层搜索，Vernata 则强化机器人 LiDAR 表征。
- Physical AI 的基础设施同时向可微、可并行和可量化发展：SoRoMoX 为软体机器人提供 GPU/JAX 物理模型；UAV3DCrop 说明真实尺度、深度和作物高度等任务指标不能被单一新视角外观分数替代。

## 最值得深入阅读

1. **Scenix**：可执行 scene program 把稀疏视图重建从“生成一张好看的场景”推进到可编辑、可验证的结构化世界表示。
2. **Addressable Memory for Video World Models**：长时视频 world model 的关键瓶颈可能是记忆地址和位置编码，而不是单纯增加上下文长度。
3. **Is Forward Prediction Enough?**：用机器人本体状态和多时间尺度关节变化约束 latent，为判断 world model 是否真的学到可控物理状态提供直接实验路径。
4. **C2Dex**：把稳定接触、局部交互几何和仿真强化学习串成从人类视频到机器人操作的完整链路，HOI 与 Physical AI 关联最紧。
5. **UAV3DCrop**：对 NeRF、3DGS 和 feed-forward 3D 重建的真实尺度评测提醒我们，面向科学或机器人应用必须同时检查外观、几何和任务量测。

## 1. SimWAM: A Simple World Action Model for End-to-End Autonomous Driving

**作者**: Zongchuang Zhao, Xin Zhou, Tianyang Xu, Zhengyang Sun, Kaixuan Zhou, Honglin Li, Dingkang Liang, Xiang Bai  
**arXiv / 发布时间与分类**: [arXiv:2608.07468](https://arxiv.org/abs/2608.07468) | 公告批次: 2026-08-10；v1 submitted: 2026-08-07 17:59:09 UTC | categories: cs.CV

**中文摘要**: SimWAM 将视频生成用作训练信号，而不是部署时必须执行的未来帧生成器。方法联合训练预训练视频专家和轻量动作专家，并用隔离注意力掩码让动作预测不依赖未来帧。训练完成后可丢弃视频分支，只保留直接输出轨迹的规划器；额外的强化学习奖励用于超越轨迹模仿。论文在 NAVSIM 达到 91.5 PDMS，并以更低延迟迁移到 nuScenes。

**方法亮点**: joint flow matching；training-only video expert；isolated attention mask；compositional driving reward。

## 2. UniJEPA: A Unified Joint-Embedding Predictive Architecture for Task-Agnostic Visual World Modeling

**作者**: An Lanji, Dawei Liu, Jin Li, Haoran Xu, Mei Chen, Yu Tian  
**arXiv / 发布时间与分类**: [arXiv:2608.07409](https://arxiv.org/abs/2608.07409) | 公告批次: 2026-08-10；v1 submitted: 2026-08-07 16:55:58 UTC | categories: cs.CV

**中文摘要**: UniJEPA 试图把图像级 photometric prediction 和视频级 temporal prediction 放进同一个 latent 空间。它用 next-embedding prediction loss 加 Gaussian regularizer，形成无需 EMA、stop-gradient 或预训练 encoder 的端到端目标。论文将 photometric prediction 解释为学习不变结构，将 temporal prediction 解释为学习随时间变化的动力学。经过离线轨迹的 action-conditioned post-training 后，模型可以把目标特征作为预测目标进行零样本规划，并在相近准确率下比生成式 world model 快数十倍。

**方法亮点**: unified image/video JEPA；Gaussian anti-collapse regularizer；goal-feature zero-shot planning。

**资源**: 项目页、代码和数据集链接未见；论文注明 ICML 2026 接收。

**推荐阅读优先级**: 高

## 3. Addressable Memory for Video World Models

**作者**: Xindi Wu, Sven Elflein, James Lucas, Olga Russakovsky, Laura Leal-Taixé, Despoina Paschalidou, Jonathan Lorraine, Aljoša Ošep  
**arXiv / 发布时间与分类**: [arXiv:2608.07408](https://arxiv.org/abs/2608.07408) | 公告批次: 2026-08-10；v1 submitted: 2026-08-07 16:55:57 UTC | categories: cs.CV, cs.LG

**中文摘要**: 论文发现，视频 world model 的 KV cache 在 rollout 超出训练时长后会因为 temporal RoPE 偏移超出分布而难以检索旧内容。直接在旋转后的表示空间平均压缩 cache 还会混合互不兼容的位置相位，进一步损坏记忆。WorldTrace 为此给每个压缩 slot 分配处于训练分布内的虚拟位置，并提出 Field 和 Landmark 两种压缩方式，分别面向时间连贯性和事件式回忆。配套 LoopBench 中，时间一致性提升 15.5%，情景回忆提升 19.5%，且无需重新训练模型。

**方法亮点**: addressable compressed cache；virtual in-distribution positions；WorldTrace-Field / Landmark；LoopBench。

**资源**: [项目页](https://research.nvidia.com/labs/sil/projects/WorldTrace/)；代码和数据集链接未见。

**推荐阅读优先级**: 高

**中文摘要**: CANIS 认为 3D canonicalization 需要语义上有意义的朝向，单靠几何 cues 很难在类别无关场景下稳定决定前后左右。它利用冻结的 image-to-3D 生成模型产生 canonical-oriented proxy，再通过输入的稀疏结构 latent 保留原物体几何。生成图像充当语义桥，图像 patch 识别 proxy 上的语义区域，深度反投影把这些 anchor 对应回输入，最后以几何匹配估计刚体变换。合成、部分观测和真实扫描实验显示，方法还能改善分类、部件分割和 dense correspondence。

**中文摘要**: 论文指出，WAM 的视觉分支若只预测静态观察，动作模型容易把高层物理状态演化和低层轨迹细节纠缠在一起。PILOT 的 Representational Deduction 让动作分支显式建模潜在状态转移 token，并把它们作为 reasoning space 中的 motion thought-of-chain 来指导轨迹生成。这样既增加了动作生成的状态监督，也让高层运动语义和低层轨迹细节可以分开解释。复杂机器人操作、泛化和少样本真实机器人微调实验均显示收益。

## 15. SoRoMoX: Fast, Differentiable, and Parallelizable Soft Robot Models

**作者**: Maximilian Stölzle, Solange Gribonval, Daniel Feliu-Talegon, Vito Daniele Perfetta, Michele Martini, Chuhan Zhang, Kiwan Wong, Mohammed Tarnini, Anup Teejo Mathew, Federico Renda, Daniela Rus, Cosimo Della Santina

**中文摘要**: SoRoMoX 是基于 Python/JAX 的可微软体机器人建模框架，补足 Cosserat-rod 模型在 GPU 并行和控制工作流上的实现缺口。统一接口覆盖 articulated、piecewise constant strain 和 variable strain 模型，并提供惯性矩阵、重力/弹性力、Jacobian 及其导数。JIT 和 GPU rollout 让系统辨识、残差力学习、computed-torque、控制增益优化、安全约束控制和强化学习训练都可在更高吞吐下运行。论文报告 CPU rollout 最快 18.1 倍、GPU 并行吞吐最高 234.6 倍，并展示高阶控制 barrier function 对接触力的约束。
