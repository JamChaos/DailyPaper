## 今日趋势

最新 2026-06-24 公告批次的三维视觉主线明显转向“可用资产和可交互表示”: ArtiTwinSplat、Pocket-SLAM、FLAT、FLUX3D、OrbitForge、3DCarGen 和 MM-TRELLIS 都在把 3DGS、triangle splats、mesh 或点云条件推向可渲染、可仿真、可部署的 3D 资产。

机器人方向的重点是让 VLA 和 diffusion policy 更接近真实物理约束: InSight 做自引导技能获取，G^3VLA 注入几何归纳偏置，NoContactNoWorries 和 TACTFUL 强调接触/触觉，Physics-Guided Diffusion Control 与 Cloth Sim-in-the-Loop 则把可行性校验和模拟器放到推理时。

世界模型继续从“预测视频”扩展为“规划和价值接口”: World Value Models 用 world model 估计机器人轨迹价值，NavWM 用视觉 foresight 做闭环导航，DynaWM 用 world model 约束运动表示。

3D 生成评估正在变严: GeoT2V-Bench 明确用重建诊断 text-to-video 的 3D 一致性，OrbitForge 也强调 coverage-aware evaluation，说明视觉逼真度已经不足以支撑 3D asset generation。

最值得优先深读的是 ArtiTwinSplat、InSight、FLAT、FLUX3D、OrbitForge、World Value Models、G^3VLA、NoContactNoWorries、NavWM 和 Pocket-SLAM；它们分别对应 articulated 3DGS digital twin、自主技能增长、显式表面生成、3DGS 原生生成、视频先验到 3D 场景、world-model value learning、几何 VLA、接触估计、导航 world model 和可扩展 3DGS-SLAM。

- 中文摘要: FLAT 关注从单张图像生成可探索 3D 场景时，现有 feed-forward 3D Gaussian 解码器缺少明确表面的瓶颈。它首次展示可以从视频扩散模型的压缩 latent 中直接解码 triangle splats，用更接近显式几何资产的表面原语替代体积高斯。方法用 ray-centered rotation parameterization 和 product window function 改善三角片回归与可微渲染梯度。它对 3D 生成的价值在于，把生成结果向游戏引擎和仿真可用的表面表示推进了一步。

  - ray-centered rotation parameterization for stable triangle regression
  - test-time refinement produces opaque real-time renderable assets

## 今日小结

今天最核心的信号是，3D 视觉论文正在同时向“显式可用资产”和“物理可执行策略”靠拢。对三维重建/生成研究，ArtiTwinSplat、FLAT、FLUX3D、OrbitForge 和 Pocket-SLAM 值得重点跟踪: 它们分别把 articulated objects、surface primitives、3DGS latent、video priors 和在线地图压缩推向更可部署的系统形态。对机器人和 Physical AI，InSight、G^3VLA、World Value Models、NoContactNoWorries、Physics-Guided Diffusion Control 和 NavWM 更关键: 它们说明下一阶段的 VLA/策略模型需要几何归纳偏置、接触感知、world-model value、物理约束推理时优化和主动 foresight。GeoT2V-Bench 则提供了一个重要提醒: 如果生成视频不能被稳定重建成一致 3D 场景，它对 3D asset 或世界模型的价值就应该被重新评估。
