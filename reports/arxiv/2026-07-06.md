## 今日趋势

今日最突出的主线是 world model 和 world-action model 进一步三维化、物理化：PhysMani、ACID、VT-WAM、Bridge-WA、WorldSample 都在把未来预测与机器人动作可执行性、触觉/接触、物理约束连接起来。

3D Gaussian Splatting 继续从渲染表示向可编辑、可评测、可用于 SLAM/语义占用的系统表示扩展：PixGS、DL-SLAM、Semantic Occupancy、Mind the Gap、AnchorSplat、MVFusion-GS 和 Structure-Aware GS 分别覆盖生成、动态建图、开放词表空间理解、benchmark 缺陷和资产修复。

4D/场景生成今天很密集：Align4D、Unified Panoramic-Gaussian、WorldDirector、SimWorlds、SPG-Layout、InvSplat、PointDiT 都指向一个共同目标，即从单图/单目/文本/任意模态得到可探索、可编辑、几何一致的动态三维世界。

人-物/手-物交互和 articulated objects 也有明显进展：JointHOI 用接触图约束 HOI 生成，ComplexMimic 把人-场景交互放进物理仿真，PWM-ArtGen/SAMoR 则补 articulated object 的结构和运动先验。

VLA 方向更强调数据与视角策略：LIME、VLAFlow、The Moving Eye、TAP 说明 embodied AI 不只是学动作头，还要学何时移动相机、怎样构造数据、如何把物理运动能力与语言任务对齐。

最值得优先深读的是 PhysMani: Physics-principled 3D World Model for Dynamic Object Manipulation、ACID: Action Consistency via Inverse Dynamics for Planning with World Models、VT-WAM: Visual-Tactile World Action Model for Contact-Rich Manipulation、WorldDirector: Building Controllable World Simulators with Persistent Dynamic Memory、Alignment Is All You Need For X-to-4D Generation、PixGS: Pixel-Space Diffusion for Direct 3D Gaussian Splat Generation。这些论文共同指向一个变化：三维视觉的中间表示正在从“能重建/能渲染”升级为“能预测、能评估可执行性、能承载接触和物理约束、能驱动机器人策略”的系统接口。

- 发布时间与分类: arXiv dateline: [Submitted on 2 Jul 2026]; official announcement batch: 2026-07-03 (Friday, 3 July 2026 official arXiv new/cross listing); categories: cs.RO, cs.AI, cs.CV

- 方法亮点:
  - inverse-dynamics action consistency for world-model planning
  - checks intermediate transition realizability
  - decision-time planner that discourages infeasible rollouts
- 代码/数据集/项目页: 项目页 https://gawon1224.github.io/ACID/
