## 今日趋势

今天最强的信号是机器人策略正在从 2D 视觉语义接口转向显式几何和接触接口。Geometric Action Model、LaWAM、UMA 和 X-Tokenizer 分别从 geometric foundation model、latent visual subgoals、3D object motion trajectories 和 action token language 切入，目标都是让 VLA/WAM 不只“看懂任务”，还要保留可执行的 3D 运动、动力学和控制信息。Qwen-RobotWorld、Kairos 与 DreamX-World 则把 world model 扩展到更通用的长时域、可交互、跨 embodiment 生成和预测。

第二条主线是触觉、手物交互和 articulated object 正在成为 Physical AI 的核心数据瓶颈。DragMesh-2、T-Rex、ART-Glove、ViTaL、HOSTPG 和 HUG 都围绕“接触如何被记录、建模和用于控制”展开，覆盖从多指手驱动 articulated objects、触觉反应式 VLA、接触采集硬件，到 markerless 4D HOI capture 和 RGB-D human grasp generation。相较于只追踪手姿态，这批论文更强调 contact geometry、contact force、物体关节运动和物理一致性。

第三条线是三维重建/仿真开始面向部署场景做工程化约束。MVM-IOD 提供工业物体 3D reconstruction 和 camera pose 的真实评测；TurboGS 关注消费级 3DGS 训练效率；RealityBridge 将 editable 3DGS driving simulation 和真实视频对齐；R2RDreamer、DataLadder 则把三维编辑、数字孪生、仿真和机器人数据生成串成可复用链路。整体看，今天的三维视觉论文更少停留在“重建漂亮场景”，更多在解决机器人、自动驾驶和仿真评估中的闭环可用性。

## 1. DragMesh-2: Physically Plausible Dexterous Hand-Object Interaction with Articulated Objects

- 作者: Tianshan Zhang, Yijia Duan, Yanjun Li, Zeyu Zhang, Hao Tang
- arXiv: https://arxiv.org/abs/2606.15133
- 发布时间与分类: arXiv submitted 2026-06-13；公告批次 2026-06-16 (Tuesday, 16 June 2026)；分类: cs.RO, cs.CV
- 中文摘要: DragMesh-2 面向多指手与 articulated objects 的物理可信交互，重点不是把物体关节轨迹重放出来，而是让目标部件运动通过持续的手-把手接触自然产生。论文指出，静态物体抓取和 articulated object 操作的关键差异在于被驱动部件不能直接施加动作，必须通过接触动力学传递。方法引入 contact-driven 框架，将 object-centric articulated generation 推进到 hand-driven dexterous HOI，并考虑不同接触载荷下的鲁棒性。它对家庭机器人、辅助机器人和类人手操作 articulated objects 很有参考价值。
- 方法亮点:
  - 将 articulated object motion 建模为多指手接触驱动的结果，而不是几何轨迹重放。
  - 显式处理 hand-handle contact、接触载荷变化和物理可行性。
  - 将 HOI 生成、dexterous manipulation 和 articulated object control 接到同一任务中。
- 代码/数据集/项目页: 项目页 https://aigeeksgroup.github.io/DragMesh-2；代码 https://github.com/AIGeeksGroup/DragMesh-2；未找到单独数据集链接。

- 中文摘要: 这篇论文直接回应 VLA/WAM 的短板: 很多模型有强语义和时间先验，但仍主要工作在 2D image frames 或 2D latent space，缺少接触操作需要的 3D 几何。GAM 将 pretrained geometric foundation model 拆成 observation encoder、causal future predictor 和 action decoding substrate，让同一 backbone 同时预测未来几何和动作。语言、proprioception 和动作历史作为条件进入 future latent token prediction，再通过后续 GFM blocks 传播和解码。它是今天最值得深读的几何化机器人策略论文之一。

- 中文摘要: T-Rex 聚焦 tactile-reactive dexterous manipulation，认为现有 VLA 常忽略高频触觉，或只用静态触觉编码器，难以做需要精细力控制的任务。论文构建 100 小时 tactile-rich dataset，并用数据高效 recipe 优先覆盖基础 motor primitives。模型侧采用 variable-rate Mixture-of-Transformers 和 temporal tactile VQ-VAE encoder，使触觉高频信号能进入 VLA 而不破坏原有视觉语言能力。实验覆盖 12 个需要 delicate force control 和 deformable object manipulation 的任务。

  - variable-rate MoT 架构兼顾触觉响应速度和 VLA 原有能力。

## 4. ART-Glove: Articulated Tactile Glove for Contact-Grounded Dexterous Interaction Capture

- arXiv: https://arxiv.org/abs/2606.16370

- 中文摘要: ART-Glove 是一个用于采集 contact-grounded dexterous demonstrations 的触觉手套系统。它用 16 个刚性功能表面覆盖手指、拇指和手掌，并通过 22 个解剖对齐关节跟随人手运动，同时记录 2048-taxel 触觉信号。系统以 120 Hz 同步采集 22-DoF joint measurements 和 dense tactile measurements，使手侧接触几何显式化。对从人类示范学习机器人灵巧操作来说，它提供了比纯手姿态更有用的接触监督。

  - 面向 downstream dexterous robot learning 的 contact-rich demonstration capture。

## 7. R2RDreamer: 3D-aware Data Augmentation for Spatially-generalized 2D Manipulation Policies

- 作者: Xiuwei Xu, Haowen Sun, Angyuan Ma, Yiwei Zhang, Zhenyu Wu, Xiaofeng Wang, Bingyao Yu, Zheng Zhu, Jie Zhou, Jiwen Lu
- arXiv: https://arxiv.org/abs/2606.17040
- 发布时间与分类: arXiv submitted 2026-06-15；公告批次 2026-06-16 (Tuesday, 16 June 2026)；分类: cs.RO, cs.CV
- 中文摘要: R2RDreamer 面向 imitation-learned manipulation policies 的空间泛化问题，用少量真实示范生成新的物体姿态、机器人配置和相机视角。它先在共享 3D frame 中编辑不完整 object point clouds 和 end-effector trajectories，再把编辑结果投影到图像空间并用 2D video completion 生成 RGB 观测。这样既保留 3D action-observation editing 的几何一致性，又避免完整仿真建模和强 3D scene parsing 的高成本。对 RGB-based 2D manipulation policies 来说，这是一种现实的数据扩展路线。
- 方法亮点:
  - 在 3D 中编辑 object point clouds 与 end-effector trajectories，保持动作/观测一致。
  - 将视觉补全放到 2D video space，适配 RGB policy 而非只服务点云策略。
  - 用 real-to-real augmentation 减少仿真场景搭建和 sim-to-real gap。

## 8. Inference-time Policy Steering via Vision and Touch

- 作者: Yilin Wu, Zilin Si, Zeynep Temel, Oliver Kroemer, Andrea Bajcsy
- arXiv: https://arxiv.org/abs/2606.14981
- 发布时间与分类: arXiv submitted 2026-06-12；公告批次 2026-06-16 (Tuesday, 16 June 2026)；分类: cs.RO, cs.AI, cs.LG
- 中文摘要: 这篇论文提出 ViTaL，一个 visuo-tactile inference-time steering 框架，用于在部署时引导预训练生成式机器人策略。它把多模态引导写成 bi-level optimization: 高层视觉 sampling-and-verification 负责长时域模式选择，低层 tactile-guided diffusion editing 负责短时域接触修正。为了让 steering 有 outcome supervision，ViTaL 学习 visuo-tactile latent world model，并设计视觉与触觉 verifier，其中触觉 verifier 可用文本条件评价 latent tactile futures。实验显示，在 3 个真实接触丰富操作任务上显著提升基础策略成功率。
- 方法亮点:
  - 高层视觉 verifier 做行为模式选择，低层触觉 diffusion editing 修正接触细节。
  - 学习 visuo-tactile latent world model 以预测和验证未来结果。
  - text-conditioned tactile reward 在 latent space 中评价触觉未来。
- 代码/数据集/项目页: 项目页 https://yilin-wu98.github.io/vital_website；未找到明确代码或数据集链接。

## 值得深读

1. Geometric Action Model
   优先读。它把 geometric foundation model 变成机器人策略的共享计算底座，直接回应 VLA/WAM 缺少 3D geometry 和 contact-aware dynamics 的问题。
2. Qwen-RobotWorld / Kairos / DreamX-World
   建议作为一组 world model 阅读。三者分别代表大规模具身视频生成、Physical AI 原生 world model stack 和交互式长时域世界生成路线。
3. DragMesh-2 / T-Rex / ViTaL
   这组三篇最能体现今天的接触与触觉主线。它们分别从 articulated HOI、触觉反应式 VLA、部署期 vision-touch steering 处理机器人操作的物理闭环。
4. UMA / LaWAM / X-Tokenizer
   这组论文关注 action representation。3D object motion trajectories、latent visual subgoals 和 semantic action tokens 都是在寻找比像素或连续动作更适合预训练和部署的机器人接口。
5. RealityBridge / TurboGS / MVM-IOD
   三维重建和 3DGS 的部署价值很强。一个面向自动驾驶仿真，一个面向 3DGS 训练效率，一个面向工业真实评测。

## 对研究的启发

- 三维重建: MVM-IOD、HOSTPG、SGFormer++ 和 GeoStream 都在强调真实场景中的几何一致性、遮挡鲁棒性和可查询语义，而不是单纯提高重建视觉质量。
- 三维生成与 3DGS: RealityBridge、TurboGS、DreamX-World 和 GeoStream 说明 3D/视频生成的重点正在转向可控相机、可编辑仿真、训练效率和长时域一致性。
- 世界模型: Qwen-RobotWorld、Kairos、LaWAM、DreamX-World 和 GAM 都在让 world model 更接近机器人策略接口，核心挑战是如何把未来预测压缩成可执行的几何、动作或 latent subgoal。
- 机器人与 Physical AI: T-Rex、ART-Glove、ViTaL、DataLadder、UMA 和 R2RDreamer 共同说明，数据采集、触觉接触、仿真转换和动作表示正在成为部署瓶颈。
- HOI / human-object interaction: 今天有明显增强，DragMesh-2、HOSTPG、HUG 和 ART-Glove 都围绕 hand-object/contact 数据与控制展开；这些工作对手-物交互建模、articulated object manipulation 和灵巧手仿真训练都很有启发。
