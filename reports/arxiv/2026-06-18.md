## 今日趋势

今天的主线非常集中: 三维一致的 world model 正在从“视频预测器”变成机器人策略、评测和数据生成的中间层。PAIWorld 和 SC3-Eval 分别从多视角 3D 一致性和自一致视频 rollout 评价切入，说明 world foundation model 要服务机器人，必须同时解决跨相机几何、动作可逆性和 rollout 漂移。DREAM-Chunk 则把 lightweight latent world model 放到 VLA action chunk 的测试时选择环节，显示 world model 不一定只用于离线仿真，也可以成为在线 reactivity 的计算预算。

第二条线是“从人类视频到机器人动作”的几何化。Do as I Do、HALOMI、Hand-4DGS 和 HT-Bench 都强调 egocentric/wrist-view、手-物接触、3D hand reconstruction、tactile geometry 或 human-to-robot embodiment gap。这里的关键启发是: HOI 数据如果只停留在 2D 视频标签，已经很难支撑灵巧操作；更有价值的是可 retarget 的 hand-object trajectory、3D keypoint/task plan、contact/tactile representation 和可执行动作。

第三条线是三维重建基础设施继续向“可规模化、可部署”推进。CAOA、FlowObject、RegimeVGGT、Splaxel 和 OneCanvas 分别处理 object-CAD alignment、few-view object completion、VGGT 加速、大规模 3DGS 分布式训练和 VLM 3D scene understanding。最值得优先深读的是 PAIWorld、MolmoMotion、FlowObject、Do as I Do、SC3-Eval、OneCanvas、Hand-4DGS 和 Zero-Shot Long-Horizon Dexterous Manipulation；它们分别对机器人 world model、3D motion prior、稀疏视角重建、HOI retargeting、策略评测、具身空间推理、手部 4D 重建和多视角 3D-grounded manipulation 提供直接启发。

## 1. PAIWorld: A 3D-Consistent World Foundation Model for Robotic Manipulation

- 作者: Yuhang Huang, Xuan Lv, Junyan Xu, Zhiyuan Yu, Jiazhao Zhang, Ruizhen Hu, Wancheng Feng, Shilong Zou, Hewen Xiao, Ziqiao Zhou, Kaiyun Huang, Zhiyu Peng, Juzhan Xu, Hang Zhao, Chenyang Zhu, Renjiao Yi, Yifei Huang, Douhui Wu, Yan Zhang, Kexu Cheng, Chunhe Song, Yunzhi Xue, Xiuhong Zhang, Leitao Guo, Yunji Chen, Bin Wu, Haibin Yu, Kai Xu
- arXiv: https://arxiv.org/abs/2606.18375
- 发布时间与分类: arXiv v1 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.RO
- 中文摘要: PAIWorld 解决机器人 world foundation model 的核心短板: 多数模型仍是单视角视频预测，缺少多相机机器人操作需要的 3D consistency。论文指出，简单拼接多视角 token 会产生跨视角物体漂移、深度不一致和纹理错位。它在 DiT world model 中加入显式跨视角通信、相机射线/外参几何编码和来自 3D foundation models 的 latent 3D-REPA 蒸馏。结果面向 multi-view policy post-training、model-based planning 和 world action models 都很直接。

  - Geometric RoPE 把相机 ray direction 和 extrinsic pose 写入注意力位置编码。
  - Latent 3D-REPA 从冻结 3D foundation model 蒸馏 3D-aware features，约束生成一致性。

## 2. MolmoMotion: Forecasting Point Trajectories in 3D with Language Instruction

- 发布时间与分类: arXiv v1 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.CV

## 3. CAOA -- Completion-Assisted Object-CAD Alignment

- 作者: Hiranya Garbha Kumar, Minhas Kamal, Balakrishnan Prabhakaran
- arXiv: https://arxiv.org/abs/2606.18429
- 发布时间与分类: arXiv v1 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.CV, cs.AI, cs.LG
- 中文摘要: CAOA 面向 indoor RGB-D scans 中的 object-CAD alignment，需要估计 9-DoF pose、rotation 和 scale。论文认为真实扫描的噪声、不完整性和 segmentation errors 会严重破坏 CAD 对齐。方法把语义/上下文感知 point cloud completion 与 symmetry-aware relative pose estimation 结合，用补全后的几何缓解真实扫描缺失。它还发布 S2C-Completion，包含超过 8,500 个来自 Scan2CAD 的 expert-annotated object-CAD pairs。
- 方法亮点:
  - Completion-assisted alignment 先补全再做 CAD pose/scale 对齐。
  - 针对 indoor scene 设计 synthetic data generation，缩小 synthetic-to-real gap。
  - Symmetry-aware loss 提升对称物体对齐鲁棒性。
- 代码/数据集/项目页: 代码 https://github.com/MinhasKamal/CAOA；数据集 S2C-Completion 随论文发布说明提供。

## 4. FlowObject: Flow Steering for Bridging Generative Priors and Reconstruction Fidelity

- 作者: Yuchen Rao, Xuqian Ren, Yinyu Nie, Sayan Deb Sarkar, Biao Zhang, Vincent Lepetit, Friedrich Fraundorfer
- arXiv: https://arxiv.org/abs/2606.19019
- 发布时间与分类: arXiv v1 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.CV
- 中文摘要: FlowObject 关注 few casual image captures 下的完整 3D object reconstruction。它指出 3D generative models 有强 completion prior 但容易 synthetic bias，3DGS 有观测表面高保真但不能推理不可见几何。论文将 sparse-view 3D reconstruction 重写为 training-free guided inverse problem，通过双空间 guidance steering flow-matching ODE trajectory。最后加入 3DGS refinement，把生成式完整性和可见表面的 photorealistic fidelity 接起来。
- 方法亮点:
  - Dual-space guidance 同时约束 generative prior 和 observed evidence consistency。
  - Training-free flow steering 避免为每类物体重新训练 3D 生成模型。
  - 3DGS refinement 修复生成输出的 synthetic-looking 外观并提升可见区域一致性。

## 7. SC3-Eval: Evaluating Robot Foundation Models via Self-Consistent Video Generation

- 作者: Wei-Cheng Tseng, Gashon Hussein, Yuzhu Dong, Allen Z. Ren, Lucy X. Shi, XuDong Wang, Sergey Levine, Zhaoshuo Li, Jinwei Gu, Florian Shkurti, Ming-Yu Liu, Quan Vuong
- arXiv: https://arxiv.org/abs/2606.18610
- 发布时间与分类: arXiv v1 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.RO, cs.CV
- 中文摘要: SC3-Eval 试图用 action-conditioned video world model 低成本评估 generalist robot manipulation policies。它指出 autoregressive rollout 会积累误差，多视角观察必须保持一致，且 evaluator 需要泛化到训练分布之外的策略行为。方法通过 forward-inverse dynamics consistency、cross-view consistency 和 test-time consistency 来稳定 video rollout。它报告对 7 个真实 VLA policies 的 closed-loop Pearson correlation 达到 0.929，适合用作机器人策略评测方向的重点论文。

  - Forward-inverse dynamics consistency 同时约束动作到帧和帧到动作。
  - Cross-view inpainting consistency 保持多相机 rollout 几何一致。
  - Test-time inverse dynamics uncertainty 用于终止偏离动作意图的 rollout。

## 9. DREAM-Chunk: Reactive Action Chunking with Latent World Model

- 作者: Wenxi Chen, Kaidi Zhang, Chi Lin, Zhiyuan Zhang, Yu She, Yuejiang Liu, Raymond A. Yeh, Shaoshuai Mou, Yan Gu
- arXiv: https://arxiv.org/abs/2606.18589
- 发布时间与分类: arXiv v1 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.RO
- 中文摘要: DREAM-Chunk 解决 VLA action chunk 一旦发出就 open-loop 执行、在随机动力学和硬件误差下脆弱的问题。它不微调原策略，而是在测试时采样多个 action chunks，用轻量 latent world model rollout 未来状态，再选择和真实观察最匹配的 chunk。这个思路把 test-time scaling 引入机器人 action chunking，用额外计算换取长时执行的反应性。论文在 Kinetix、多个操控任务和两种机器人平台上验证了鲁棒性提升。
- 方法亮点:
  - Latent world model 用于测试时候选 action chunk 选择。
  - 不需要额外 policy fine-tuning，能叠加到 chunking-based VLA。
  - 多候选未来 rollout 改善 stochastic dynamics 下的 reactivity。

## 10. OneCanvas: 3D Scene Understanding via Panoramic Reprojection

- 作者: Bartłomiej Baranowski, Dave Zhenyu Chen, Matthias Nießner
- arXiv: https://arxiv.org/abs/2606.19253
- 发布时间与分类: arXiv v1 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.CV, cs.AI, cs.LG, cs.RO
- 中文摘要: OneCanvas 提出一种让 pretrained VLM 做 3D scene understanding 的轻量表征，不依赖复杂 3D geometry encoder。它把多视角 patch features 用深度和相机位姿 unproject 到 3D world coordinate，再映射到单个 equirectangular panoramic canvas 上。额外的 3D position embedding 弥补从 world position 到 angular canvas coordinate 时损失的深度信息。对 embodied AI 来说，它提供了一个把多视角几何压成 VLM 可消费图像接口的实用方案。
- 方法亮点:
  - 多视角 patch features 共享一个 3D coordinate system 后再 panoramic reprojection。
  - 不需要大改 VLM backbone，可像普通图像一样输入。
  - Spatial pretraining curriculum 通过程序化放置 patch features 合成空间推理监督。

## 11. RegimeVGGT: Layer-Wise Spatially Preserving Redundancy Removal for Visual Geometry Grounded Transformer

- 作者: Jinhao You, Shuo Lyu, Zhuohang Lyu, Tanxuan Li, Zibo Zhao, Jiaxiang Hu, Kai Tang, Yichen Guo
- arXiv: https://arxiv.org/abs/2606.18439
- 发布时间与分类: arXiv v1 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.CV, cs.RO
- 中文摘要: RegimeVGGT 面向 VGGT 这类单次前向多视角 3D reconstruction 模型的可扩展性问题。论文用 spectral、probing 和 causal analyses 发现不同层有不同几何作用: 浅层缺少 cross-view structure，中层驱动 cross-view alignment，深层对 dense geometry 冗余但对 pose 仍重要。它据此做 layer-wise U-shaped compression，保护几何/边缘 salient tokens 和 pose-critical path。训练免费获得 6.7x speedup，对大规模 3D foundation model 部署很实用。
- 方法亮点:
  - 分层识别 VGGT 的 shallow/middle/deep 几何作用差异。
  - Saliency-Guided Banded Merging 保留几何与边缘关键信息。
  - Selectively Protected K/V Downsampling 保护跨帧空间覆盖和相机/register tokens。

## 12. Splaxel: Efficient Distributed Training of 3D Gaussian Splatting for Large-scale Scene Reconstruction via Pixel-level Communication

- 作者: Wenqi Jia, Zhewen Hu, Ying Huang, Yu Gong, Stavros Kalafatis, Yuke Wang, Wei Niu, Chengming Zhang, Ang Li, Sheng Di, Yuede Ji, Bo Fang, Miao Yin
- arXiv: https://arxiv.org/abs/2606.18588
- 发布时间与分类: arXiv cross-list 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.DC, cs.CV
- 中文摘要: Splaxel 针对 large-scale scene reconstruction 中 3DGS 需要跨多 GPU 优化上亿 Gaussians 的问题。现有 distributed 3DGS 要么按区域切分导致全局不一致，要么交换 Gaussian-level 信息导致通信爆炸。Splaxel 改为 pixel-level local rendering 和 global composition，各 GPU 只交换 partial pixel values，而不是同步所有 Gaussians。论文在最多 120M Gaussians 的大场景上报告最高 7.6x speedup，同时保持重建质量。
- 方法亮点:
  - Pixel-level communication 保持数学一致性并稳定通信成本。
  - Geometric/transmittance visibility prediction 减少像素级冗余。
  - Conflict-free camera-view consolidation 提升多 GPU 利用率。

## 14. Object-Centric Residual RL for Zero-Shot Sim-to-Real VLA Enhancement

- 作者: Kinam Kim, Namiko Saito, Heecheol Kim, Katsushi Ikeuchi, Jaegul Choo, Yasuyuki Matsushita
- arXiv: https://arxiv.org/abs/2606.18953
- 发布时间与分类: arXiv v1 公告批次 2026-06-18 (Thursday, 18 June 2026)；分类: cs.RO
- 中文摘要: 这篇论文问的是: 只在仿真中训练的 residual RL 能否零样本增强真实 VLA。它冻结 base VLA，用 object poses、proprioception 和 base VLA action 训练轻量 residual policy，避免 image-based residual 的视觉 sim-to-real gap。通过在仿真中 replay 同一批遥操作示范来对齐 real/sim VLA 行为，再用 pose noise 和 dropout 提升部署鲁棒性。真实 FR3 上 5 个任务平均成功率从 42% 提升到 76%，并能用改进 rollout 反过来再训练 base VLA。
- 方法亮点:
  - Object-centric state 作为 residual policy 观测，弱化视觉域差。
  - Paired sim/real VLA via teleoperation replay 保持动作分布对齐。
  - Residual-corrected rollouts 可作为自改进监督数据。
- 代码/数据集/项目页: 项目页 https://www.microsoft.com/en-us/research/articles/object-centric-residual-rl/；未找到明确代码或数据集链接。

## 今日重点阅读建议

如果只读 3 篇，建议优先读 PAIWorld、Do as I Do 和 FlowObject。PAIWorld 代表多视角 3D-consistent world model 对机器人操作的直接落地；Do as I Do 代表 HOI/人类视频转灵巧手数据的关键路线；FlowObject 则把 3D generative priors 和 3DGS fidelity 接起来，对稀疏视角对象重建很有启发。

如果关注机器人评测和闭环策略，再读 SC3-Eval、DREAM-Chunk 和 Object-Centric Residual RL。它们共同说明 world model、residual RL 和 test-time compute 可以作为 VLA 的外部增强模块，而不只是端到端模型内部的隐式能力。

如果关注三维基础模型和空间推理，再读 OneCanvas、RegimeVGGT、Splaxel 和 MolmoMotion。今天的趋势表明，3D foundation model 的下一步不是只追求更强 benchmark，而是要服务 embodied AI 的实时性、多视角一致性、可扩展训练和可行动的 3D motion representation。
