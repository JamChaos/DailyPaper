## 今日趋势

今天最集中的主线是 world/action model 开始显式吸收三维结构和接触动力学。$\mu_0$ 把世界模型的预测目标从像素未来改成 3D interaction traces，WAM4D 用 spatial register tokens 把几何先验注入 WAM，ContactWorld 则系统比较视觉-触觉世界模型在接触丰富操作里的关键表征属性。这些工作共同说明，面向机器人控制的世界模型不再满足于“视频看起来合理”，而是要把可执行动作、接触区域、遮挡几何和长时域物体运动都编码进模型接口。

第二条线是三维重建与生成更强调“语义/编辑/仿真可用性”。Pano3D 将 feed-forward 3D reconstruction 与 3D panoptic segmentation 放进统一框架，Instruct-Particulate 用可指令化的 kinematic specification 扩展 articulated object 标注，MUSE 把文本驱动 3D 场景生成改造成带记忆和验证的增量式编辑流程。VideoWeave 则从视频生成侧反向说明，几何一致性需要进入 latent denoising，而不是只在生成后用深度或点云约束修补。

机器人与具身方向今天覆盖导航、示范采集和单视角操作。FloVerse 与 AnyGoal 都把空间先验做成可持续更新的导航记忆，EgoGuide 用头戴/腕部同步视角和在线几何质量引导提高 UMI 式示范效率，SCDP 与 ReactVLA 分别从单 RGB 全局视角精细操作和低延迟 VLA 动作生成切入。整体看，Physical AI 的瓶颈正在从“是否有大模型策略”转向“几何、接触、视角和实时性如何进入数据与策略闭环”。

- 中文摘要: 这篇论文把机器人世界模型的预测对象从 dense pixels 或 embodiment-specific actions 改成 salient interaction points 的平滑 3D 轨迹。$\mu_0$ 关注物体、工具、手和接触区域等关键点，让模型学习动作引发的物理变化，同时避免像素级重建消耗大量容量。TraceExtract 自动从多源视频中抽取 3D supervision，包括关键点、全局对齐轨迹和层级语言 caption，从而支持大规模预训练。它对机器人学习的启发是，世界模型可以用更紧凑且跨 embodiment 的 3D motion interface 承接视频和控制。

  - 结合视觉语言 backbone 与 3D motion 预测，服务 embodiment-agnostic robot learning。

- 中文摘要: ContactWorld 是一个围绕视觉-触觉 world models 的 benchmark 和系统实证研究，覆盖插入、拆解、旋拧和探索性交互等 12 个接触丰富任务。论文发现，空间结构化且时间连续的表征最能支撑长时域规划，点云观测相比 wrist/front RGB 视角显著提升平均规划成功率。触觉并不是简单堆模态就有效，它依赖跨模态表征兼容性，否则会引入噪声或错配。对手-物/工具交互研究来说，这篇论文提供了评估接触动力学世界模型的清晰基准。

- 中文摘要: Pano3D 关注 feed-forward 3D reconstruction 中语义理解不足的问题。它在已有 3D reconstruction backbone 上加入 set-based mask decoder，并用几何与语义损失联合训练，让 dense reconstruction 和 3D panoptic segmentation 互相促进。论文展示该框架能适配 online 和 all-to-all attention 两类重建 backbone，并在 ScanNet、ScanNet200、ScanNet++ 上取得 3D panoptic segmentation 的强结果。对三维场景理解来说，这代表从“重建形状”走向“重建可查询语义世界”。

  - geometric loss 与 semantic loss 联合训练，减少重建和理解的割裂。

## 7. VideoWeave: Unlocking Geometric Consistency in Video Generation via Joint Geometry-Video Modeling

- 中文摘要: VideoWeave 面向视频生成中的 3D 几何漂移和视角变化下不合理运动。它不依赖显式深度图、点云或 3D reconstruction 作为硬条件，而是把几何模型的隐式特征适配为 geometry latents，并与 video latents 在共享 denoising space 中联合建模。这样几何信息在训练时影响生成分布，同时减少上游几何重建误差对视频生成的放大。论文还构建 GeoVid-80K，用于支撑几何一致视频生成后训练。

  - geometry latents 与 video latents 共享 denoising 空间。
  - GeoVid-80K 为几何一致视频生成提供训练数据。

## 10. FlowMo-WM: A World Model with Object Momentum and Hidden Ambient Drift

- 作者: Yitao Jiang, Luyang Zhao, Muhao Chen, Devin Balkcom
- arXiv: https://arxiv.org/abs/2606.13817
- 发布时间与分类: arXiv submitted 2026-06-11 18:46:43 UTC；公告批次 2026-06-15 (Monday, 15 June 2026)；分类: cs.RO, cs.LG
- 中文摘要: FlowMo-WM 关注很多世界模型忽略的真实问题: 物体并不总是只受当前动作支配，还会因为惯性、风或水流等隐藏环境漂移持续运动。论文提出端到端视觉 world model，从 image-action histories 中无监督推断 object-centric motion state 和 long-history context。短历史 latent 负责物体动量，长历史 context 负责缓慢变化的外生漂移，再用 residual transition 分离动作基础动力学与上下文漂移。它对水面机器人、移动物体操作和非平稳环境建模都有参考价值。

  - 显式区分 object momentum 和 hidden ambient drift。
  - short-history latent 与 long-history context 分别编码快变量和慢变量。
  - zero-context residual transition 分离 action-conditioned dynamics 与 context-dependent drift。

## 13. ReactVLA: Fast and Lightweight Reactive Robot Manipulation via Improved Mean Flow Action Generation

- 作者: Yanzhao Guo, Wenkai Chen, Jianwei Zhang

- 中文摘要: ReactVLA 针对 diffusion-based VLA 的实时闭环瓶颈。传统扩散动作生成依赖多步采样，延迟高，难以用于快速反应式操作。ReactVLA 结合 improved Mean Flow action generator，把多步扩散采样压缩到一到少数几步，同时用 Attention Residuals 动态路由深度特征，保留任务相关多模态信息。它在 LIBERO、RoboIMI 和真实机器人任务上评估，重点是把 VLA 从高质量离线动作分布推进到低延迟闭环控制。
- 方法亮点:
  - improved Mean Flow 将动作生成从多步扩散降到 one-to-few-step。
  - Attention Residuals 动态选择/路由任务相关多模态表示。
  - 同时评估大规模仿真 benchmark 和真实机器人操作。

- 中文摘要: AnyGoal 是一个 training-free 多机器人终身导航架构，用 VLM 驱动 frontier-based exploration，并通过共享 2D Gaussian Bayesian Value Map 积累目标相关证据。相比 dense 3D snapshot memory，它用按像素均值/方差 posterior 表示目标价值，再通过 depth-cone mask 融合 VLM 分数。frontier 排序结合 VLM-as-judge softmax 和 Bayesian UCB，多机器人分配则使用空间分离惩罚和 commitment hysteresis。它说明开放词汇导航可以通过轻量概率空间记忆持续积累，而不一定依赖端到端重训练。

  - 2D Gaussian Bayesian Value Map 持续累积目标相关证据。

## 16. Occupancy-Grounded Room Segmentation for Hierarchical 3D Scene Graphs

- 作者: Carlos Cueto Zumaya, Iacopo Catalano, Jorge Pena-Queralta, Wallace Moreira Bessa
- arXiv: https://arxiv.org/abs/2606.13727
- 发布时间与分类: arXiv submitted 2026-06-11 09:36:15 UTC；公告批次 2026-06-15 (Monday, 15 June 2026)；分类: cs.RO
- 中文摘要: 这篇论文关注室内机器人 hierarchical 3D scene graph 的 room layer。现有 3DSG 系统常用 place clusters、wall planes 或 segmentation outputs 构造房间节点，导致 room nodes 没有统一几何评价标准。作者提出 occupancy-grounded 3DSG pipeline，将房间锚定到由 occupancy decomposition 得到的 tracked free-space regions，并为每个房间提供明确 polygonal footprint。Matterport3D 实验显示该方法比 Hydra 式 place-connectivity baseline 找回更多房间实例，但精度有所下降。
- 方法亮点:
  - room nodes 以 occupancy-derived free-space regions 为几何锚点。
  - 输出 explicit polygonal footprints，便于与 room annotations 匹配评价。
  - 以统一几何标准评估 3DSG room layer，而非只看拓扑连通。

## 值得深读

1. $\mu_0$
   今天最值得优先读。它把 action-induced physical change 压缩成 3D traces，是连接互联网视频、语言标注和机器人世界模型的一个很清晰接口。
2. WAM4D
   对 WAM/VLA 研究很关键。它提出一种训练期吸收 4D 几何、推理期保持轻量的折中方案，直接回应三维约束和低延迟动作生成之间的矛盾。
3. ContactWorld
   对 Physical AI 和手-物/工具接触操作很重要。它不是只给一个新策略，而是问清楚视觉-触觉世界模型到底需要什么表征属性。
4. Instruct-Particulate
   对 articulated objects、机器人仿真和可交互 3D asset 都值得看。kinematic specification 作为条件接口，有机会连接 VLM、mesh processing 和操作仿真。
5. Pano3D / VideoWeave
   建议作为一组三维生成与重建论文阅读。前者把语义直接并入 feed-forward 3D reconstruction，后者把几何一致性前置到视频生成 latent space。

## 对研究的启发

- 三维重建: Pano3D、MooMIns 和 SplatlessDF 都在把重建结果变得更可用，一个服务语义查询，一个服务多实例 6D pose，一个服务机器人距离场/规划。
- 三维生成: VideoWeave 和 MUSE 显示生成模型正在从一次性产物转向带几何一致性、需求记忆和局部编辑能力的工具链。
- 世界模型: $\mu_0$、WAM4D、ContactWorld 和 FlowMo-WM 的共同点是把世界模型输出结构化为轨迹、几何 token、接触表征或隐式漂移，而不是只生成 RGB 视频。
- 机器人与 Physical AI: EgoGuide、SCDP、ReactVLA、FloVerse 和 AnyGoal 都把“部署约束”放进方法中心，包括示范数据效率、单视角限制、低延迟闭环和空间先验记忆。
- HOI / human-object interaction: 今天没有新的强 human-object interaction 论文进入主体；但 ContactWorld、Instruct-Particulate、EgoGuide 和 SCDP 都在提供面向手-物/工具交互建模的邻近技术，包括接触世界模型、articulated object 结构和操作示范采集。
