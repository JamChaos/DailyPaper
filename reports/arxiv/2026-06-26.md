## 1. PhysiFormer: Learning to Simulate Mechanics in World Space

- 作者: Yiming Chen, Yushi Lan, Andrea Vedaldi
- arXiv: https://arxiv.org/abs/2606.27364
- 发布时间与分类: arXiv API published 2026-06-25T17:59:00Z; official announcement batch: 2026-06-26 (/list cs.CV/new); categories: cs.CV
- 中文摘要: PhysiFormer 把物理世界模型从像素空间转到世界坐标中的 3D mesh 顶点轨迹。模型以初始顶点位置、速度和材料类型为条件，用 diffusion transformer 直接采样刚体或弹性物体的未来运动。它不显式写入刚性、因果或传统仿真器约束，而是通过时间、空间和对象维度分解的 attention 学习多物体动力学。结果对机器人、图形和物理设计都有启发，因为它把可视化世界模型推进到几何坐标和材料条件下的可采样物理预测。
- 方法亮点:
  - world-coordinate mesh trajectory diffusion
  - time-space-object factorized attention for multi-object mechanics
  - generalizes to mixed materials, real geometries, and larger object counts
- 代码/数据集/项目页: 项目页 https://yimingc9.github.io/physiformer；代码 https://github.com/yimingc9/PhysiFormer。
- 推荐阅读优先级: 高

## 4. Fast LeWorldModel

- 作者: Yuntian Gao, Xiangyu Xu
- arXiv: https://arxiv.org/abs/2606.26217
- 发布时间与分类: arXiv API published 2026-06-24T17:59:59Z; official announcement batch: 2026-06-26 (/list cs.LG/new); categories: cs.LG, cs.CV, cs.RO
- 中文摘要: Fast LeWorldModel 关注 reconstruction-free visual world model 在规划阶段的计算瓶颈。原 LeWorldModel 需要自回归地一步步 rollout 候选动作序列，规划慢且误差会随 horizon 累积。Fast-LeWM 改为 action-prefix prediction: 对动作序列前缀并行编码，直接预测不同前缀执行后的未来 latent。这样既减少规划时间，也让模型学习多步动作效果如何逐渐累积，对机器人视觉规划中的 latent world model 很实用。
- 方法亮点:
  - action-prefix prediction replaces autoregressive latent rollout
  - parallel evaluation of candidate action sequences
  - reduces planning time and slows latent error growth over horizon

## 总结

今天最强的信号是世界模型和三维表示都在补物理闭环: PhysiFormer 和 Neural Voxel Dynamics 把预测空间改成 3D mesh/voxel，PhysEditWorld 用可控物理参数提供数据，Hallucination in World Models 则从覆盖率角度解释生成式世界模型为什么失真。对三维重建和 3DGS 研究，PanoImager、SatSplatDiff、RayPE、SceneStyler 和 Vis4GS 的共同启发是: 生成先验必须被相机几何、阴影、深度或 primitive-level 证据约束，才能减少跨视角幻觉。对机器人和 Physical AI，KRVF、RelAfford6D、VibeAct、Tactile-WAM、PressMimic 和 OmniContact 都强调一个方向: 语义和视觉表示必须显式接上来源、接触、压力、触觉或 6D 约束，才能在真实操作中稳定闭环。
