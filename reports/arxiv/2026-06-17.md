## 今日趋势

今天最强的主线是“可执行三维世界”正在成为机器人学习和 world model 的共同接口。GASE、MagicSim、AnnotateAnything 和 WireCraft 分别从 3DGS 场景重建、统一仿真运行时、3D asset 自动标注和工业 DLO 仿真 benchmark 切入，目标都是把视觉资产转成可执行、可评测、可生成数据的 Physical AI 基础设施。GeneralVLA-2 和 FR3D 进一步说明，机器人规划和未来预测不再满足于 2D video latent，而是需要 object-centric 3D evidence、persistent 3D latent 和显式 ego-motion/world-motion 解耦。

第二条线是 HOI/手物交互从“识别交互”走向“可用于机器人迁移的接触数据”。EgoInfinity 把互联网 RGB 视频提升为 metric 4D hand-object representations 并 retarget 到机器人；MOCHI 修复协作式多人人物交互中的抓取、接触和手指细节；HOI-DETR 强化 hand-object/object-object interaction detection；EAGG 则把 grasp generation 与末端执行器拓扑和接触几何绑定。这里的共同启发是: 未来 HOI 数据集如果不能输出 6-DoF object pose、contact-relevant state 或可执行轨迹，对机器人学习的价值会明显受限。

第三条线是 VLA/World-Action 模型继续从离线 imitation 走向可规划、可记忆、可在线改进。Qwen-RobotManip 强调跨 representation、motion 和 behavior 的大规模对齐；MuseVLA 把温度、声音、雷达等传感器包装成按需调用的 VLA 工具；WAM-RL、PearlVLA 和 ThinkingVLA 分别探索 world/action 联合 RL、latent plan refinement 和 interleaved visual-language reasoning。最值得优先深读的是 GASE、EgoInfinity、GeneralVLA-2、FR3D、ActWorld、Qwen-RobotManip、MoonSplat 和 MOCHI，它们分别代表三维重建到仿真、HOI 数据引擎、几何 VLA、3D world model、交互式世界模型、机器人基础模型、在线 3DGS 和协作 HOI 数据增强的关键方向。

## 1. GASE: Gaussian Splatting-Based Automated System for Reconstructing Embodied-Simulation Environments

- 作者: Jiawei Zhang, Yiming Yan, Chao Liang, Nuo Xu, Seson Sun, Qichen Zhang, Yuhao Xu, Yantai Yang, Yingqiao Wang, Qin Jin, Zhipeng Zhang
- arXiv: https://arxiv.org/abs/2606.17520
- 发布时间与分类: arXiv submitted 2026-06-16；公告批次 2026-06-17 (Wednesday, 17 June 2026)；分类: cs.RO, cs.CV
- 中文摘要: GASE 面向 embodied agents 的仿真环境快速构建，用全景相机阵列采集多视角视频，再将前景物体和静态背景分别重建为可导入物理仿真的资产。论文指出，现有 3DGS 重建流程在数据采集、前景分割和场景导入上仍然低效，阻碍了大规模 sim-to-real 数据生成。GASE 用 camera-pose-based 2D object extraction 和高质量 inpainting 改善资产生成质量，并在真实机器人 manipulation/navigation 中报告小于 10% 的 real-data 性能差距。它很适合作为“3DGS -> 仿真 -> 策略训练”闭环的系统论文阅读。
- 方法亮点:
  - 用多视角全景视频做高效环境扫描，并把前景物体与背景独立重建。
  - 结合 camera pose 的 2D foreground extraction 与 scene inpainting，提升 3DGS asset 可用性。
  - 将重建资产无缝导入 physics simulators，用于 manipulation 和 navigation policy training。

## 2. EgoInfinity: A Web-Scale 4D Hand-Object Interaction Data Engine for Any-View Robot Retargeting and Video-to-Action Robot Learning

- 中文摘要: EgoInfinity 不是静态数据集，而是一个把互联网人类操作视频转成机器人训练数据的 4D hand-object interaction data engine。它集成 perception、segmentation、reconstruction、interaction-aware refinement 和 retargeting，将任意视角 RGB 视频提升为 metric 4D hand-object representations，包括 hand trajectories、6-DoF object poses 和 contact-relevant states。论文强调 cross-module metric calibration 和 interaction-aware refinement，以减少纯视觉重建常见的漂移和接触不一致。对 open-world robot learning 来说，它把视频数据规模优势转化为可执行机器人行为。

  - motion retargeter 将 3D hand motion 编译为不同机器人形态的可执行关节轨迹。

- 中文摘要: GeneralVLA-2 针对 VLA 系统中的两类瓶颈: object-centric 3D evidence 不稳定，以及长程机器人记忆缺少质量、冲突和几何相关性治理。它提出 GeoFuse-MV3D，用多视角和 soft visual-hull 支持约束 SAM3D-style reconstruction，减少单目 hallucination。它还把 KnowledgeBank 升级为 governed long-term memory，显式记录 confidence、lifecycle、verifier 和 conflict metadata。对几何 VLA 来说，这篇论文的价值在于把 3D reconstruction 和可控记忆同时纳入 robot planning 接口。

## 9. MOCHI: Motion Enhancement of Collaborative Human-object Interactions

- 作者: Jiye Lee, Yonghun Choi, Jungdam Won
- arXiv: https://arxiv.org/abs/2606.18243
- 发布时间与分类: arXiv submitted 2026-06-16；公告批次 2026-06-17 (Wednesday, 17 June 2026)；分类: cs.CV, cs.GR, cs.RO
- 中文摘要: MOCHI 面向 collaborative multi-human object interaction 中的噪声捕获问题，重点修复 hand-object contact misalignment、motion jitter、temporal inconsistency 和缺失的 finger-level articulation。它先从噪声 body input 优化生成 physically plausible 且语义一致的 hand grasps，并扩展成完整 hand-object interaction sequences。随后用 diffusion-based noise optimization 和 single-person motion priors 优化多人 full-body motion，同时加入 human-object 和 human-human interaction objectives。它对 HOI/MHOI 数据清洗、生成式数据增强和机器人协作操作建模都很有价值。

  - 两阶段增强 noisy MHOI capture: grasp optimization + diffusion-based full-body refinement。
  - 通过 interaction objectives 将 human-object 与 human-human 约束注入 motion prior。
  - 支持不同人数和物体几何变化下的 MHOI creation 与 data augmentation。

## 13. WAM-RL: World-Action Model Reinforcement Learning with Reconstruction Rewards and Online Video SFT

- 作者: Zezhong Qian, Xiaowei Chi, Yu Qi, Haozhan Li, Zhi Yang Chen, Shanghang Zhang
- arXiv: https://arxiv.org/abs/2606.17906
- 发布时间与分类: arXiv submitted 2026-06-16；公告批次 2026-06-17 (Wednesday, 17 June 2026)；分类: cs.RO
- 中文摘要: WAM-RL 解决 World-Action models 依赖 expert trajectories、难以通过真实交互持续改进的问题。它把 world model 和 action model 放进 RL 框架中联合优化，让两者在 online interaction 中共同演化。论文的关键结论是，只优化 actor 对短时任务有帮助，但长时任务需要同时在线训练 world model 和 actor。对机器人操作来说，这意味着 world model 不能只是离线视觉预测器，还应参与策略改进和 reward shaping。
